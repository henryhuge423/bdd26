# Stage reports

Each stage folder keeps its report sources, PDFs, figures and available numerical/build
verification together. English, Chinese and plain-language Chinese versions should explain
the same evidence and limitations. Historical report bodies and audit addenda remain intact.

| Stage | Scope |
|---|---|
| [I](stage_report_1/) | Original three pillars, baselines and informative negative results |
| [II](stage_report_2/) | Detection architectures, working resolution and decode controls |
| [III](stage_report_3/README.md) | Matched seeds, existence-filtered P2 and audit corrections |
| [IV](stage_report_4/README.md) | HV controls, DSB stop gates and inference cost |
| [V](stage_report_5/README.md) | Typing probe, detector consensus and candidate-quality stop |

A link or citation edit to TeX does not rebuild PDFs; build-verification files describe the
build they record. New scientific results belong in a new stage or an explicitly dated
addendum with artifact-bound verification. [Documentation index](../README.md).
