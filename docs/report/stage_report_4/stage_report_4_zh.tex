\begin{abstract}
上一阶段的 EF-P2 在保留原尺度预测的前提下补入两倍尺度候选，以极小的整体指标代价稳定提升了 Dead 类的分割质量，但没有回答三个更根本的问题：两倍尺度的 Dead 增益从何而来，Dead 短板能否靠训练侧的专家分支解决，以及两套模型的完整推理代价是多少。本阶段围绕这三个问题开展机制实验。首先，四臂对照实验（E2a）把 HV 目标的固定面积门槛从尺度效应中分离出来：x1 降低门槛只能复现两倍尺度 Dead 增益的 9.59\%，不足以替代尺度本身；在把门槛折算到原生像素面积口径配平后，x2 相对 x1 仍承担全部 bPQ 代价，并保留大部分 Dead 增益。其次，为检验“Dead 与常见类在共享解码器上存在容量级梯度冲突”这一前提，Dead 专家分支（DSB）在训练前设置了四道预注册闸门：A、C、D 三项放行，而 B 项梯度冲突探针在修正取样方式后的重跑显示，64 个 Dead 阳性批次上解码器复合梯度余弦均值为 $+0.749$、最小值 $+0.594$、无一批为负，梯度强同向而非冲突；据此该研究线按预注册的止损规则关闭，未启动任何 GPU 训练。最后，推理成本实测表明两模型系统耗时为单模型 x1 的 6.09 倍；按预注册规则，EF-P2 的定位由候选部署方案调整为机制证据与教师候选模型。本阶段另完成一次全仓库一致性审计，更正了若干历史转录误差，并重建了两个丢失的实验产物。全部实验未读取测试折，亦未产生新的三划分测试成绩。
\end{abstract}
\noindent\textbf{关键词：}细胞核实例分割；PanNuke；机制归因；预注册闸门；梯度冲突；推理成本

\section{研究背景与本阶段问题}

阶段报告三给出了一个边界清晰的正面结果：EF-P2 在九组划分--种子配对上将 Dead PQ 平均提高 0.00699，同时将 bPQ 的平均损失控制在约 $-0.000009$\cite{reports}。但它同时留下了三个悬而未决的问题。第一，Dead 增益的来源不清楚——两倍工作尺度同时改变了采样密度、特征尺度、解码常数和训练监督的构成，收益无法归因。第二，Dead 短板的训练侧解法尚未被排除——此前的负结果集中在像素加权、平衡采样与免训练找回，模型内部为稀有类设置专家分支的方案尚未检验。第三，两套模型的部署代价从未测量，EF-P2 的实用定位悬而未决。

10 月 6 日的复盘将这三个问题确立为正式议题，并给出最小实验集 E0--E5 与三条候选路线\cite{next}。复盘中的代码排查带来一项直接决定本阶段首组实验的发现：HV 目标构造沿用了官方实现的 30 工作像素面积门槛，实例小于该门槛时其整个 HV 目标被置零；而在两倍尺度下，同样的门槛只相当于约 7.5 个原生像素。也就是说，x1 与 x2 的小实例几何监督在训练开始前就不相同，任何把 x2 收益直接归因于“分辨率”的解释，都必须首先排除这一混杂因素。

本阶段完成的工作依次为：
\begin{enumerate}
\item 开展 E2a 四臂对照实验，将工作尺度与 HV 门槛两因素交叉，隔离监督门槛对 Dead 增益的贡献；
\item 执行 DSB 四道预注册闸门，在投入 GPU 训练前检验 Dead 专家分支的全部前提假设，并在闸门失败时按预注册规则关闭该研究线；
\item 完成 E0 推理成本实测，按预注册规则确定 EF-P2 的部署定位；
\item 进行全仓库一致性审计，核对文档、代码与实验产物，更正历史误差并重建丢失产物。
\end{enumerate}

本阶段所有训练与探针只使用训练折和验证折，没有读取任何测试折，也不产生新的三划分测试成绩。E2a 为单划分、双种子的验证集机制实验；DSB 全部闸门在同一组冻结检查点上执行；E0 只计时、不评测。三者结论的适用范围分别在相应各节说明。

\section{实验设置与通用口径}

模型与训练配方沿用阶段报告三：CellViT\cite{cellvit} 以 UNI\cite{uni} 为编码器，训练 130 轮，批大小 16，前 25 轮冻结编码器，初始学习率 $3\times10^{-4}$、逐轮乘 0.85 衰减，推理不使用测试时增强。E2a 与 DSB 闸门在 split 1（训练 fold 1、验证 fold 2）上执行；验证折 fold 2 含 2,523 张图、19 种组织、59,872 个真实细胞核实例（ground-truth instances），其中 Dead 884 个，分布在 70 张图，图像内部 741 个、接触图像边界 143 个。两个随机种子训练出的模型共享同一批对象，不构成两批独立样本。

指标口径与阶段报告三一致：mPQ 为官方图像--组织聚合的多类全景质量，bPQ 忽略类别，Dead PQ 只在含 Dead 真值的图像上计算；strict 口径把“无该类真值却预测出该类”的图像也计入惩罚，与官方口径并报。梯度余弦、毫秒每图等本阶段新增的量在各节单独定义。表中 $\Delta$ 均为前者减后者的带符号差值，如 $+0.00982$ 即百分制下 0.982 分。

\section{HV 目标支持门槛：一个先于训练的混杂}

复盘阶段在 CPU 上直接调用仓库的 \code{hv\_targets} 构造函数，对同一 $64\times64$ 标签中的完整矩形核做精确两倍最近邻放大，统计非零 HV 像素数（表~\ref{tab:hvprobe}）。16 与 25 像素的核在 x1 下 HV 目标整体为零，在 x2 下则具有完整的方向距离场；30 像素的核恰在 x1 门槛边缘。被门槛排除的实例仍保留核像素与类型（NP/TP）监督，并非被完全忽略，但分水岭解码所依赖的 HV 几何目标被置为全零，并\textbf{在损失中被显式监督至零}，而非作为忽略区域排除在损失之外。

\section{E2a：HV 门槛与工作尺度的四臂对照}

\subsection{完成状态}

四臂 $\times$ 种子 \{19, 1\} 共 8 次训练全部完成：每个日志均含 130 个 epoch 且无重复记录，最终检查点齐备，训练源码冻结于提交 \code{c6e7e92}。每臂另做一次哈希绑定的审计重推（最终检查点、无 TTA、同一解码常数），8$\times$6 个端点上审计与原始评估的差值全部精确为零，排除了在两次评估之间择优汇报的可能。八个训练日志记录的训练循环时间合计 41.76 小时，在共享 A100 上运行，仅作为完成性记录，并非受控的吞吐基准。HV 分支完整 CPU 测试 210 项通过、3 项 CUDA 依赖跳过。

四项对比给出四个可分开陈述的判断\cite{hvres}：

\begin{enumerate}
\item \textbf{x1 降门槛不能替代 x2。}Dead 差值在两个种子间方向相反（$-0.00138$ / $+0.00426$），bPQ 在两个种子上均下降。x1\_hv8 的 strict Dead 均值虽较高，仍无法弥补官方口径下的不稳定性与整体代价。
\item \textbf{x2 内门槛效应是候选信号，不是稳健改进。}hv30 相对 hv120 的官方 Dead 在两个种子上均提高（$+0.01083$ / $+0.00880$），均值 $+0.00982$，但 bootstrap 区间跨零，strict Dead 在 seed 1 下降。
\item \textbf{配平支持水平后，尺度效应仍伴随 bPQ 代价。}两组 x2$-$x1 对比的 bPQ 区间均完全位于零以下，且两个种子方向一致；官方 Dead 均值为正的同时，strict Dead 在全部四个 x2$-$x1 种子对上为负。官方与 strict 两种口径必须一并报告。
\item \textbf{因果机制尚未定位。}固定面积门槛只排除了一个特定混杂；尺度同时改变采样、特征与目标离散化，训练进度安排（编码器解冻时学习率已衰减至 $5.16\times10^{-6}$）等混杂仍未隔离。
\end{enumerate}

对象级统计进一步刻画了门槛效应的性质。以验证折固定的 741 个内部 Dead 为分母，x1\_hv30 的匹配率为 61.27\%，x2\_hv120 为 70.99\%——在原生像素面积口径配平后，内部 Dead 匹配率仍由尺度提高近 10 个百分点。而在 x2 内部，把门槛从 120 降到 30 仅使平均内部匹配数从 526.0 增至 526.5（两个种子合计仅多 1 个）：$+0.00982$ 的官方 Dead 增益并非来自内部完整核的额外找回，更可能源于掩码形状与误报结构的变化，本轮未做进一步分解。接触图像边界的 Dead 匹配率同样由尺度解释（40.21\%$\to$48.25\%），门槛在 x2 内对其几乎没有影响。

\subsection{研究决策与闸门 A 的规则计算}

E2a 的直接决策是：默认 \code{hv\_min\_size=30} 不变；x2\_hv30 保留为冻结的机制参照；不把本轮任何数字当作三划分收益发布。对后续 DSB 研究线，预注册的闸门 A 以点估计代入规则：x1 降门槛复现的 Dead 增益占比 $r/R=0.00144/0.01503=9.59\%$，未达到 50\% 的换基线条件，也未达到 90\% 的全解释降级条件，且 x1\_hv8 伴随 $-0.00130$ 的 bPQ 代价。因此 DSB 基线维持 x1\_hv30，架构线不降级。该比值只是冻结规则的代入值，不构成对门槛贡献的因果估计。

\section{DSB：Dead 专家分支的四道预注册闸门}

\subsection{设计与闸门逻辑}

DSB 的假设链是：如果 Dead 与常见类在共享解码器上存在\textbf{容量级}梯度冲突（H1），那么把 Dead 检测解耦为模型内专家分支（同构 NP+HV 双头、仅 Dead 阳性图计算专家损失、EF 式去重并入）有望在不损害聚合指标的前提下恢复内部 Dead 召回（H2）。设计要点为：编码器与既有 NP/HV/TP 三分支保持不变，仅新增专家分支；不使用过采样（平衡采样在 C1 已有负结果），不使用 pos\_weight（97\% 的批次为纯负样本，会污染 BatchNorm 统计），改用损失掩蔽。文献核查未发现“类解耦专家 + 细胞核实例分割 + PanNuke 官方三折 + 等参对照”的正面工作，最近的类比是图像分类领域的 GS-MoE 与半监督腺体分割的 Semi-MoE\cite{gsmoe,semimoe}。完整设计、预算与止损规则冻结于预注册规格\cite{dsbspec}。

按规格 \S6，任何 GPU 训练开始前须依次通过四道闸门，全部通过方可进入开发轮；任一失败则关闭整条研究线、只保留机制证据。CPU 侧实现（模型、目标、损失、TTA、命令行、合并选择、蒙太奇与四个闸门脚本）按测试驱动开发逐任务完成并提交；该分支在闸门流程结束后合入 master，保留为已通过测试的工具代码，从未用于任何训练。

\subsection{闸门 A、C、D 的结果}

\textbf{闸门 A（proceed，基线 x1\_hv30）。}规则计算见上节：9.59\% $<$ 50\%，未触发更换基线；$<$ 90\%，未触发降级。输入数字经独立复核，与 E2a 冻结快照逐位一致。

\textbf{闸门 C（proceed）。}在验证折 fold 2 上扫描 Dead 专属解码阈值 $\tau_{\mathrm{dead}}\in\{0.5,0.4,0.35,0.3\}$（0.5 即基线）：Dead PQ 由 0.16386 最高升至 0.16601（$\tau=0.4$），$\Delta$Dead 峰值 $+0.00214$，$\Delta$bPQ $+1.1\times10^{-5}$。峰值远低于 $+0.005$ 的关闭线，说明免训练的决策级解耦无法带来足够的 Dead 召回提升，架构级解耦的前提仍然成立。基线 Dead PQ 与官方评估逐位一致；该菜单的重解码路径使 mPQ/bPQ 基线与官方评估存在 $10^{-7}$ 量级差异，本报告只引用其 Dead 数字。

\textbf{闸门 D（pass）。}把 fold 2 全部 267 个未匹配的内部 Dead 真值以 IoU 0.7 的收缩掩码 oracle 加入基线预测：Dead PQ 由 0.16386 升至 0.31992，$\Delta$Dead $+0.15606$，bPQ $+0.00145$，mPQ $+0.00231$；精确掩码变体 $\Delta$Dead $+0.24533$。该上界远高于 $+0.01$ 的通过阈值：只要能找回漏检的内部 Dead，收益量级即可达到现有水平的十倍以上。这与“Dead 短板首先是检测召回问题”的诊断一致。

\subsection{闸门 B：首跑判 VOID 与修正重跑后的失败}

闸门 B 在冻结的 split1 检查点上测量 Dead 像素组与常见类像素组损失的梯度余弦：两组掩码不相交，同一批数据一次前向、分别反传，对共享解码器参数取复合余弦；冲突定义为余弦为负的批次比例 $\geq$30\% 或逐层显著为负。

首次运行（10 月 8 日 00:58）被判 VOID 而非失败：预冻结计划指定“顺序取前 256 张 fold 1 图像”，而这 256 张全部为 Breast 组织、恰含 1 张 Dead 阳性图；64 批中有 63 批的 Dead 损失结构性地为零，却被当作非冲突批次计入分母，致使冲突比例在尚未测量任何梯度几何之前就被限制在 1/64。唯一有效批的解码器复合余弦为 $+0.269$。探针机制本身经核查无误（掩码不相交、一次前向、\code{retain\_graph}；参数集与解码器等价），缺陷出在预冻结的取样设计与零损失批次的分母计入方式。规格 \S10 的止损规则未被触发；修正案（Dead 分层种子取样覆盖全部 65 张 Dead 阳性图、分母只计 Dead 活跃批、$n_{\mathrm{active}}<16$ 判 VOID、补齐逐层单侧 $t$ 检验与 Holm 校正）先行登记于台账并新增四个测试用例，经确认后重跑，全程约数分钟 GPU 时间。

\subsection{按预注册止损关闭}

规格 \S10 预注册：任一闸门失败即关闭整条研究线，不升级算力。闸门 B 失败后，DSB 的冒烟轮、开发轮与确认轮全部取消，蒙太奇盲审不再需要，已准备的开发轮队列脚本未启用。四道闸门合起来留下的是一组机制证据：Dead 短板是检测召回问题——像素重加权与平衡采样此前已证伪，决策阈值解耦仅能带来 $+0.002$，专家架构解耦的梯度冲突前提不成立，而检测级 oracle 上界高达 $+0.156$。解法不在这四个方向上；后续要么引入新的检测监督或数据（路线 C 的跨模态条件），要么接受 EF-P2 式的两阶段候选补入并如实报告其成本（路线 B）。

\section{讨论与后续工作}

\subsection{本阶段的局限}

\begin{enumerate}
\item \textbf{E2a 为单划分、双种子实验。}全部对比在 split 1 的验证折上进行，bootstrap 区间只覆盖图像抽样；Dead 的四个对比区间均跨零，x2 内的门槛效应属于候选信号，有待三划分与更多种子确认。
\item \textbf{闸门 B 只覆盖训练收敛后的检查点。}早期训练动态与损失幅度不在测量范围内；止损所依据的规格先于测量冻结。
\item \textbf{DSB 的 H2 未经检验。}整条研究线在进入训练前的闸门阶段即告终止，结论限于“解耦前提不成立”，不涉及专家分支本身的有效性。
\item \textbf{E0 为单机共享 GPU 的实际耗时（wall-clock）测量。}绝对毫秒不可直接迁移，比值在观测窗口内稳定；模型加载、评测与并行融合未计入。
\item \textbf{本阶段没有新的三划分测试成绩。}各结论或为验证折机制发现，或为既有结果的更正与定位调整；测试折多轮复用的限制与阶段报告三相同。
\end{enumerate}

\subsection{后续方向}

复盘给出的三条路线中，本阶段已完成其中机制与成本两部分的检验（E2a 与 E0 均以闸门化方式进行）。下一步优先级不变\cite{next}：先做 E1 验证候选盲审（x1 接受、x2 独有接受/拒绝、随机背景四组，专家裁决“当前视野无法判定”），把 EF-P2 新增候选的“未匹配”成分拆成 debris、形状偏差与疑似漏标；若盲审支持，再做路线 B 的训练内交叉拟合效用学习（以 $P(\mathrm{match})\cdot E[\mathrm{IoU}\mid\mathrm{match}]>q/2$ 为代理判据），并与冻结 EF-P2、低维回归以及相同算力预算下的 TTA/集成相对照。路线 A 的裁剪一致性机制实验与路线 C 的跨模态监督维持条件启动。DSB 保留的闸门工具（分层蒙太奇、梯度探针、oracle 上界）可在这些路线中复用。

\section{结论}

本阶段未追求新的测试分数，而是把阶段报告三留下的三个问题分别推进到明确的答案。第一，HV 目标支持门槛是真实存在的混杂因素，但贡献只占小部分：x1 降低门槛仅复现两倍尺度 Dead 增益的 9.59\%，配平支持水平后 x2 仍承担全部 bPQ 代价并保留大部分 Dead 增益，strict Dead 在全部四个种子对上为负——尺度效应的主体在别处。第二，Dead 专家分支的前提假设被证伪：在训练完成的检查点上，Dead 与常见类的梯度高度同向（64 批复合余弦均值 $+0.749$、零负批），连同此前已证伪的重加权、增益仅 $+0.002$ 的阈值解耦与高达 $+0.156$ 的检测级 oracle 上界，Dead 短板的解法指向新的检测监督或数据，而非在现有监督上重新分配容量；该研究线按预注册止损关闭，未花费确认轮算力。第三，两模型系统的实测耗时为单模型（x1）推理的 6.09 倍，EF-P2 定位调整为机制证据与教师候选模型。全仓库审计确认主要结果均可复现，历史数字的转录误差已就地更正。机制结论、成本边界与更正后的历史记录，构成本项目当前的进度基线。
