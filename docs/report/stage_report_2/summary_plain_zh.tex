\section*{背景：上一份报告留下了两个猜想}

上一阶段的结论（见阶段报告一导读）：AI 在病理切片上识别细胞核，最困难的一类是\textbf{凋亡
核}——细胞死亡后留下的皱缩、碎裂、深染的残迹。过去五年发表的模型，在这一类上的得分始终停
留在 0.13--0.19，其它类别一般在 0.4 以上。对错误逐项拆解后，我们确认：问题不在于“认错”，
而在于“看不见”——约 38\% 的凋亡核完全没有被检出；更换数据集、更换训练技巧，均无济于事。

当时留下两条未经检验的出路，本阶段的工作就是把它们逐一检验完毕：

\begin{enumerate}
\item \textbf{换一种架构。}常见模型的做法是“先为每个像素打分，再把相邻像素围成核”（下称
      “描边派”）。另一派“找点派”先预测每个核的中心点，再围绕这些点组装轮廓——文献中
      最亮眼的凋亡核成绩，恰恰出自找点派（一个名为 KongNet 的模型）。
\item \textbf{把图像放大。}凋亡核体积小（面积中位数约为普通核的三分之一），在 256 像素的
      工作分辨率下，每个核只占十几个像素——模型也许并非不会识别，而是根本看不清。
\end{enumerate}

按照事先约定的严格标准（数据按官方方案分为三份；参数只在验证部分上调整；测试部分只评估
一次；每个结论都以多个随机种子重复验证），两条猜想的答案均已得出。

\section*{发现一：换用“找点派”架构，不仅没有更好，反而低了 11 分}

KongNet 的作者公开了三份分别训练的模型权重，但未说明各份对应数据的哪个划分。我们先解决
了这个问题：将每份权重在数据的三个部分上各测一遍，观察它在哪个部分“记得最牢”——模型在
训练过的数据上成绩会明显偏高，据此即可对号入座，全程不使用测试数据。

随后按严格标准复评：KongNet 的整体得分只有 0.346，比我们测过的“描边派”中最弱者还低
11 分；文献中最亮眼的凋亡核成绩（逐核配对打分的 $F_c$，0.59），在我们的口径下只剩 0.34。

失败的方式很能说明问题：\textbf{相互接触的同类核被“粘”为一体}。它合并相互接触核的比例，
是描边派模型的三至四倍——而凋亡核恰恰常以“碎块群”的形态出现（核碎裂，karyorrhexis）。
换言之，凋亡核的困难一半在“找不到”，另一半在“找到了却分不开”，而找点派的组装方式加剧
了“分不开”的问题。结论：这不是更换架构流派所能解决的问题。

\section*{发现二：另一个更强的模型，同样未能兑现凋亡核的收益}

我们还复评了 LKCell-L——在我们能取得公开权重的模型中，它的整体成绩最好（论文成绩
0.508）。两个发现：

\begin{itemize}
\item 它的各项指标一律比论文低约 1.5 分。这种“整体平移”说明差异来自评测流程（选择哪个
      存档点、如何调整后处理），而不是我们测错了。
\item 在同等条件下，它分割轮廓确实更准（不分类别的分割得分更高），但\textbf{类型识别反
      而更差}，凋亡核得分比我们自己的基线低 2.2 分。它寻找凋亡核的能力其实更强——找到的
      核却过不了“类型配对”这一关，最终仍无法兑现为凋亡核得分。
\end{itemize}

两个模型指向同一个结论：\textbf{模型整体的强弱，与能否解决凋亡核，是两回事。}

\section*{发现三：把分辨率提高一倍，凋亡核确实改善——但代价明码标价}

这是本阶段的主要结果，前后共五步。

\paragraph{第一步：放大。}把工作分辨率从 256 像素倍增到 512，其余一切（模型、训练配方、
数据）保持不变。结果：事先登记的凋亡核指标\textbf{全部}改善——图像内部（不贴图像边缘）的凋亡
核漏检率从 35\% 降至 25\%，连最困难的子宫脱落细胞团也从 0.041 升至 0.055。但整体分数全面
下降 1.8--2.6 分（指标不同，降幅不同）。按事先定下的“凋亡核改善且整体不退步”标准判定：
失败。

\paragraph{第二步：代价出在哪里？}三个证据锁定了位置。其一，下降与凋亡核的改善\emph{不在
同一批图像上}——凋亡核改善的图像，整体分数基本未变，丢分的图像恰恰不含凋亡核。其二，把核
按大小分层（图~\ref{fig:zhsize}）：面积 200 像素以下的小核\textbf{全部}改善（凋亡核也不
例外），核越大下降越多——受损的是\emph{大核}，与类别无关。其三，被正确匹配的核，轮廓质
量完全没有变化。大核不是被识别得更差，而是\textbf{被切碎了}：一个核最多被切成 7 块“马赛
克”，而外轮廓仍贴合标准答案（图~\ref{fig:zhmontage}）。

\paragraph{第三步：真凶是两个写死的数字。}“把 512 的预测图缩回 256 时丢失了信息”是最直
观的嫌疑，但被“匹配核轮廓质量不变”排除。顺着线索追查到模型背后的经典后处理代码：分水岭
（一种把图像视为地形、沿“山脊”切开相邻核的传统算法）这一步中，有两个\textbf{以像素为单
位写死}的常数——面积小于 10 平方像素的目标一律丢弃；边缘检测的窗口宽度固定为 21 像素。分
辨率提高一倍后，若换算回\emph{真实的物理尺寸}，这两个门槛实际上已被悄然放宽——面积门槛
只相当于原来的四分之一，窗口宽度只相当于原来的一半。于是，本应被滤除的细碎噪声混入了预测列表；大核内部纹理上又出现多
余的切割信号，将整核切碎。几乎整个领域都在使用这套沿袭自 HoVer-Net 的后处理代码，而这一
隐患此前未见文献指出。

\paragraph{第四步：修复，以及一个“杠杆”。}修复方案在实施前已预先登记：把两个常数按放大
倍数补回（面积门槛乘 4、窗口宽度乘 2）。只改两行代码，代价即可收回 50--87\%（依指标不
同），凋亡核增益分毫未损，还略有增加。随后再加入一个只在验证数据上选定的“杠杆”——把切
碎的\emph{同类}相邻块合并回去、丢弃贴着图像边界的细条。加上这一杠杆后，全部 9 次重复实验
（3 个数据划分 $\times$ 3 个随机种子）的整体分数均严格改善。

\paragraph{第五步：诚实的终局。}最后的检验是 $3\times3$ 的划分 $\times$ 种子网格
（图~\ref{fig:zhgrid}），判定标准事先写定。结果一分为二：

\begin{itemize}
\item \textbf{代价是稳健的}：整体分数的下降在每一次重复中方向一致，幅度约为随机波动（更
      换随机种子重训带来的差异）的 5 倍——这是真实效应。
\item \textbf{凋亡核增益是脆弱的}：折算下来只有随机波动的 0.4--0.7 倍，五次同种子配对比较
      中失利一场，还有一个数据划分的种子均值由正转负。
\end{itemize}

\begin{figure}[ht]
\centering
\includegraphics[width=0.98\linewidth]{figs/chart_seed_grid_zh.png}
\caption{种子网格：3 个数据划分 $\times$ 3 个随机种子。右图为整体分数——橙点（512 分辨
率）均低于蓝点（基线），代价确凿；左图为凋亡核分数——橙蓝交错，其中一个划分上橙色均值反
而更低，增益脆弱。}
\label{fig:zhgrid}
\end{figure}

因此，最终的答案是：\textbf{分辨率提高一倍，确实让 AI“看见”了更多将死的细胞}（漏检率下
降 7 个百分点，这一项在所有重复中方向一致），但它并非没有代价——整体分数约下降 0.8 分。
这是一次明码标价的交换，是否值得，取决于下游更看重哪一端；至于“凋亡核类得分提高 0.5 分”
这样的头条数字，在这项基准的噪声水平下不足为凭——哪些数字可信、哪些不可信，报告中均已
说明。
