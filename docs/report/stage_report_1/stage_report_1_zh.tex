\begin{abstract}
在 PanNuke 上，更换 backbone 只能带来 1--2 个 mPQ 点的收益，而\textbf{Dead}（凋亡）类
的 PQ 在所有已发表模型中停滞在 0.13--0.18。本阶段报告回答两个问题：Dead 为何停滞，以及病理
视觉--语言模型与可控生成模型这两类“新范式”能否改善稀有类缺陷或改进鲁棒性评测。我们首先
在官方 3-fold 协议下复现两个基线（HoVer-Net 0.456 mPQ、CellViT-UNI 0.500），并加入第三
个评估器 HoVer-NeXt-T（0.458）——其初始移植得分 0.358 被证明源于解码伪影，而非模型差距。
其次，我们证明 Dead 缺陷集中于\textbf{检测}而非分类：38.5\% 的 Dead 真值核没有任何重
叠预测；在这些漏检核内部，前景头沉默（平均核概率 0.16），而类型头却给出
P(Dead)$\approx$0.26。第三，在预注册的多种子协议下，五项干预全部无效或有害：模型侧的病理
VLM（CONCH）后处理重分类、免训练漏检找回与类别/尺寸加权的前景损失，以及数据侧的失败驱动
copy-paste（Dead PQ $-0.031$）与标签自洽的上下文内扩散合成（mPQ 持平）。第四，我们构建
了三架构 $\times$ 三数据集的零样本跨域基准（CoNIC、MoNuSAC、PUMA）与
\emph{PanNuke-CF}——固定 PanNuke 标签、对组织上下文与染色做干预后重渲染的反事实测试
集。反事实压力测试\textbf{反转}了真实跨域排序（6 个评估点 Spearman $-0.89$；架构均值
$-1.00$）：轴分解显示架构间的真实迁移差异几乎全部位于检测轴，而标签固定的渲染从构造
上就无法触及检测；在它能施压的分型轴上，反事实排序与真实迁移一致。结论：反事实渲染是
有效的\emph{分型}压力测试而非迁移代理；Dead 检测缺陷是架构性的——我们测试的所有损失级
与数据级干预都对它无效，且该缺陷跨域依然存在（三架构在 PUMA 上的平均 Dead PQ 仅
0.002--0.033，域内为 0.13--0.18）。
\end{abstract}

\section{引言}
\label{sec:intro}

细胞核实例分割与分类是计算病理学的标准任务，PanNuke~\cite{gamper2019pannuke} 是其代表性
基准：19 种组织、205,000 个标注核，以组织平均 mPQ（mean panoptic quality）评测。其排行榜
长期停滞不前：五年的架构进步只换来约 1--2 个 mPQ 点
（HoVer-Net~\cite{graham2019hovernet} 0.463 $\rightarrow$
CellViT-SAM-H~\cite{horta2024cellvit} 0.498 $\rightarrow$ 当前最佳约 0.51），而
\emph{Dead}（凋亡小体）类始终停在 PQ 0.13--0.18，粘连核的 merge/split 错误也持续存在。
两类新范式有望带来比 backbone 工程更大的收益：一是病理视觉--语言
模型~\cite{lu2024conch}，可作为类型分类的先验；二是可控生成模型~\cite{le2025pixcell}，
可充当“组织模拟器”——定向合成训练数据，或在干预下重渲染评测图像。

本项目围绕三个预注册的支柱展开，每个支柱都事先写明通过/失败标准——负结果只有在验收
标准事先固定时才有价值。\textbf{A}：语言锚定的类型头——用 CONCH 文本空间攻克稀有类的
\emph{分类}问题；\textbf{B}：失败驱动的合成——用生成数据攻克 Dead 与小核的\emph{检测}
问题；\textbf{C}：评测——用真实跨域迁移与反事实测试集检验现有的鲁棒性度量。三个支柱现
均已收官，本报告记录各项发现。贡献如下：

\begin{enumerate}
\item \textbf{单一严格协议下的复现}（\S\ref{sec:setup}）：HoVer-Net、CellViT-UNI
由我们自行训练并按同一协议评测（一律取 last checkpoint、解码超参仅在验证折上调节）；
HoVer-NeXt-T 使用官方发布的分折（per-fold）权重（其验证折选出的 checkpoint；折划分已核对，
与我们的完全一致），配以同样仅在验证折上调好的解码。并顺带量化了一个已发布评测配方（16 个随机颜色 TTA 视图 + 在\emph{测试折}上
调阈值）能把分数抬高多少（\S\ref{sec:baselines}）。
\item \textbf{Dead 缺陷的分解}（\S\ref{sec:diagnosis}）：它是一个集中在小核与孤立核上
的\emph{检测}失败——前景头看不见，类型头却部分“看见”——这正是所有类型侧干预都失败的原因。
\item \textbf{预注册的负结果}（\S\ref{sec:pillarA}、\S\ref{sec:pillarB}）：CONCH 重分
类、免训练找回、损失重加权（3 种子）、失败驱动 copy-paste、上下文内扩散合成全部无效或
有害；并给出了种子噪声标定，说明多大的效应量才可信。
\item \textbf{$3{\times}3$ 架构 $\times$ 数据集零样本跨域基准}（\S\ref{sec:external}），
其中 PUMA 是我们所能找到的唯一较大规模的外部凋亡 Dead 标签来源；CoNIC 与 MoNuSAC 的
转换与核验管线一并给出。
\item \textbf{PanNuke-CF}：标签固定的反事实渲染基准（\S\ref{sec:cf}），并在机理层面判定其
有效性：外观反事实在构造上无法检验检测能力，因此在 mPQ 层面\emph{反转}真实迁移排序，但作为
分型压力测试仍然有效。
\end{enumerate}

所有结果来自同一代码库与同一评测器；该评测器与官方 PanNuke-metrics 逐位一致
（官方发布的 \texttt{class\_stats.csv} 存在列交换 bug，已在仓库中记录）。

\section{相关工作}
\label{sec:related}

\paragraph{PanNuke 模型。}HoVer-Net~\cite{graham2019hovernet} 提出的水平--垂直
watershed 解码至今仍被多数后续工作（以变体形式）沿用。CPP-Net~\cite{cppnet}、
HoVer-NeXt~\cite{hovenext}、CellViT~\cite{horta2024cellvit} 及其后续
（LKCell、CellVTA、CellViT++~\cite{horta2025cellvitpp}）、
PromptNucSeg~\cite{promptnucseg} 均落在 0.46--0.51 的 mPQ 区间内。其中只有部分工作发布了
分折（per-fold）权重；若官方权重是在全量数据上训练的（如 HoVer-Net 官方权重），便只能用于
管线 sanity check，绝不能当作测试结果——本报告全程遵守这一区分。

\paragraph{病理基础模型与 VLM。}冻结的病理基础模型在稠密任务上并不必然优于 ImageNet
CNN~\cite{mindthegap}；病理 VLM CONCH~\cite{lu2024conch} 在稠密预测上与纯视觉模型持平，
但额外提供对齐的文本空间。纯提示接口在细胞核任务上表现极差（SAM3 式提示在 PanNuke 类任务
上 mIoU $<10\%$）；最接近的已有工作（PromptNu、MONCH）要么没有官方 PanNuke 配置，要么
只做语义分割。据我们所知，“病理 VLM 文本空间 + 实例分割 + 官方 PanNuke mPQ”这一组合尚无
先前工作。

\paragraph{生成式增强与压力测试。}已有报道显示，合成数据对\emph{稀有类}有帮助
（DiffMix、HistoSmith、NucleiMix~\cite{nucleimix}），但据我们所知没有工作在官方 3-fold
PanNuke 协议下以 mPQ 报告——已有研究均使用非标准划分与 Dice/AJI/F1。影像模型的反事实压力
测试已在放射学中得到演示~\cite{cfstress}；实例分割中尚无对应工作。PixCell~\cite{le2025pixcell}
（连同其 Cell-ControlNet）是当前最强的开源可控细胞核生成器，也是我们合成实验与反事实
渲染器的共同基础。

\section{实验设置}
\label{sec:setup}

\paragraph{数据与协议。}PanNuke 第 1--3 折，官方划分（train/val/test $=1/2/3$、
$2/1/3$、$3/2/1$）；所有数字为 3-split 均值，不做基于测试集的早停：我们自行训练的
HoVer-Net/CellViT-UNI 取 last checkpoint，HoVer-NeXt-T 用官方发布的分折（验证折选出）
checkpoint。外部数据集（\S\ref{sec:external}）为零样本：每个数据集都映射到 PanNuke 5 类，
缺失类按官方协议从 mPQ 中排除。

\paragraph{指标。}官方组织平均 mPQ/bPQ（对 PanNuke-metrics 的逐位一致复现）、strict mPQ
（对图中不存在的类别计罚其 FP，而非忽略）、AJI/AJI$^+$、检测 $F_d$ 与分类 $F_c$（12\,px
质心匹配）、以及 IoU 0.5 的错误分解（matched / merged / missed-no-overlap /
missed-poor-shape / split，按类拆分）。TTA（8 个二面体变换，HV 通道重映射）单独报告。

\paragraph{噪声标定（用于每个判定）。}用同一 CellViT-UNI 配方训练 3 个种子：std 在
mPQ 上为 0.0021，但在 Dead PQ 上为 \textbf{0.0074}；Dead 的图像 bootstrap CI 半宽为
0.02--0.03。我们据此执行以下规则：单种子 Dead 变化低于约 0.01--0.015 视为噪声；每个干预的判定
必须是 3 种子（或多折）结论，附配对、组织分层图像 bootstrap 95\% CI；所有决策只在验证折上
做出。

\section{支柱 A：Dead 缺陷是检测缺陷}
\label{sec:pillarA}

\subsection{CONCH 的类别语义只在上下文尺度出现（可行性）}
我们在真值核上直接测试零样本 CONCH 分类：紧裁剪接近随机水平（32\,px 裁剪为 0.27）；改用
全上下文 patch 加半径受限注意力池化后，平衡准确率达到 0.695（R\,=\,32\,px，每 patch 一次
前向）；用 LLM 形态学描述替代纯类名，再提高 8--11 个点。在五类之中，Dead 是 CONCH 文本
识别效果最好的一类（召回 0.88），而分割模型恰恰在 Dead 上表现最差。不过在自然分布下，
CONCH 对 Dead 的零样本精度只有约 0.10，因此只能作为互补信号。线性头的文本锚定初始化只在少样本情形（每类 $\le$25 核）
下有帮助，在全量 PanNuke 标注下则不起作用。这把支柱 A 的重心从分类转移到了检测。

\subsection{管线内重分类：无效}
我们将 CONCH（零样本或线性探针）融合进 CellViT-UNI 的类型决策，所有可调参数均在验证折
上确定（表~\ref{tab:retype}）：没有任何配置超过管线自身的 seg-vote 类型决策；重校准对
照与最佳融合持平。TTA 下，验证调参为两种融合都选择了 $\alpha=0$。

\subsection{免训练找回：无效}
在原始 NP/HV/TP 图上扫描 96 个配置，覆盖前景混合、Dead 先验增强、blob 阈值、孤立体找回
四族（3 个 split，配置在验证集上挑选）：每个族与仅调阈值的对照相比，差距都在
$\pm0.0004$ test mPQ 之内。漏检的 Dead 核无法从该模型的输出中找回。

\subsection{损失侧消融：无效或是交换}
split 1 上的像素加权前景 CE，配 3 种子基线：Dead 像素权 $\times$11（M1）无效；完全均衡
采样器（C1）无效；小核权 $\times$6（M2）在一个种子里看似有希望（$+0.0042$ test mPQ，
CI 不含 0），但 3 种子上 mPQ $-0.0010$ $[-0.0043,+0.0022]$，且 bPQ \emph{显著}下降
$-0.0024$ $[-0.0048,-0.0002]$，Dead 增益 $+0.0108$ $[-0.0021,+0.0238]$ 不显著——这是一
次交换而非贡献；它也清楚地说明：在该基准上，低于约 0.004 的单种子 mPQ 效应只能算种子
运气。

\section{支柱 B：失败驱动的合成同样无法修复检测}
\label{sec:pillarB}

\subsection{失败布局长什么样}
我们在折外数据上挖掘失败布局（用 split-2 模型预测折 1；折 3 测试上模式相同），发现漏检
的 Dead 核是\emph{孤立}的：完全不与任何邻居接触的 Dead 核，漏检率为 0.39--0.42（占全
部 Dead 的约 90\%），而漏检 Dead 与其它核接触的比例 $<$5\%。merge 则是同类成簇的现象（73--82\% 的
merged Dead 与另一 Dead 相接触，即核碎裂碎片群）。起初假设的跨类接触在数据中很罕见，并
非失败模式。因此我们放弃了原计划的“Dead 紧贴 Neoplastic”干预，改为：(1) 向空基质插入
孤立小核；(2) 密集同类簇。

\subsection{CP1：失败驱动 copy-paste 是有害的}
供体核（50--400\,px，Dead 权重 0.4）以 8\,px 间距粘入无核基质，且在几何/光度增强
\emph{之前}粘贴（粘贴核与宿主 patch 同步增强；视觉审查发现了 v1 中的可学习捷径并将其修
复，同时修复的还有边界碎片与未标注核碰撞）。相对 3 种子基线的结果（split 1，测试折 3）：
$\Delta$mPQ $+0.0009$ $[-0.0024,+0.0043]$，但 $\Delta$Dead \textbf{$-0.0310$}
$[-0.0576,-0.0100]$（TTA 一致）。损害集中在\emph{分型}而非检测：匹配 Dead 的类型正确率
.690$\rightarrow$.609，混淆双向增加。但验证折上 Dead 的变化方向恰好\emph{相反}
（$+0.0235$）：Dead PQ 在折间摆动约 0.05，这是噪声规则的第三次独立确认。一种解释是：把
真实外观移植进新上下文，等于教会模型把“干净基质中的孤立小核”当作偏向 Dead 的线索，从而
模糊了类型边界。

\subsection{上下文内合成（PixCell）：从外观差距到结构性障碍}
PixCell-256 + Cell-ControlNet，以折 1 真实掩码为条件：核的放置是忠实的（约 95\% 的掩码
对象在正确位置/尺寸渲染，中位 IoU 0.68），但 20$\times$ 生成器在 40$\times$ PanNuke 上
有结构性外观差距（平色块染色质、高频 $-24\%$、大掩码欠渲染且尺寸偏置）。LoRA 适配（两
轮，r16 与 r8 加快照选择）反而使所有图像空间指标都\emph{变差}，遂放弃该路线；改用对配对
真实 patch 的 Reinhard LAB 迁移来消除颜色差距（OD-L1 0.072$\rightarrow$0.009）。在锁定
配方（基座 + 配对上下文 + Reinhard）下，32 张图的冒烟测试通过了视觉审查（颜色与配对真实
相差约 3/255），但审查暴露了一个结构性障碍：ControlNet 条件是\emph{二值}掩码，上下文
embedding 不含类别信息，生成器因此无法表达类别特定的外观——729 个保留对象中没有一个被判
为 Dead（P(Dead)$\le 0.005$）。若强行使用供体类别标签，只会原样复现 CP1 的失败（标签与
外观相互矛盾）。因此 SYN1 采用\emph{类别无关、教师自洽}的标签，任何效果都只能经由检测
环节产生：1146 张合成图以
50\% 混合，其余与基线配方完全一致。结果（测试折 3）：mPQ 0.4900 vs 基线 0.4951（3 种子
区间 0.4910--0.4951 的底部），Dead 0.1521 vs 0.1424（约 $+1$ 点，处于种子噪声边缘；
PQ$^+$/DQ$^+$/SQ$^+$ 全部持平，说明这点 Dead 收益来自更好的类型配对而非更好的分割），
Inflammatory $-1.0$--$1.6$ 点。按预注册规则判定：无效。

\subsection{支柱 B 判定}
在不重训生成器条件的前提下，Dead/小核检测缺陷无法被现有的数据侧手段修复：真实外观移植
（CP1）反而损害 Dead 分型，标签自洽的上下文内合成（SYN1）无效。连同支柱 A 的三项无效结
果（重分类、找回、损失重加权），所有证据都指向同一结论：该缺陷是架构性的。

\subsection{有效性：反事实压力反转真实排序}
\label{sec:validity}

在 6 个评估点（3 架构 $\times$ 2 splits）上，将 CF 降幅与真实跨域降幅做相关：Spearman
$\rho=-0.89$（\texttt{ctx}，精确置换 $p=0.033$），\texttt{tissue} $-0.89$，
\texttt{stain} $+0.43$ 不显著。在架构均值上（这是更公平也更严格的检验——同一架构的两个
split 近乎重复），ctx 与 tissue 都给出 $\rho=-1.00$：完全倒置——域内受上下文交换损害最
重的模型（CellViT）是真实迁移中最鲁棒的，反之亦然。

表~\ref{tab:axes} 给出了机理。架构间的真实迁移差异集中在\emph{检测}轴（CellViT 的
$F_d$ 损失 0.007；HoVer-Net 0.163——其 MoNuSAC 崩溃），分型间隙增量则彼此接近

的核，CF 的 $F_d$ 降幅因此在架构间齐平（0.08--0.10），不携带排序信息。在 CF \emph{能}
施压的地方——上下文/染色错配下的分型——其排序与真实分型迁移一致（架构均值
$\rho=+1.00$；全部 6 点 $+0.71$/$+0.83$）。必须指出的局限：$n=3$ 个架构（架构均值
$|\rho|=1$ 对应的精确 $p=1/3$；更有力的证据是 3 架构 $\times$ 2 splits 的完全符号倒置加上
轴分解机理），且架构间真实分型差异（区间 0.069--0.088）远小于检测差异（0.007--0.163）。

\paragraph{判定。}PanNuke-CF 是有效的\emph{分型压力测试}：它对各架构分型鲁棒性的排序与
真实迁移一致。但它\emph{不是}迁移代理——若当作代理使用，排序会被反转，因为它的盲区（检
测）恰恰是真实迁移差异所在。仅干预外观的反事实天然带有这一构造性限制；要探测检测鲁棒性，
需要对\emph{布局}（密度、杂乱、伪影）的干预，而非外观。

\section{讨论}
\label{sec:discussion}

\paragraph{为什么三个支柱都以负结果收场。}三个支柱共享一个隐含假设——Dead 性能受限于信息
（语言先验）或数据（合成样本），而非检测架构。诊断结果恰恰相反：漏检 Dead 核在 83\%
的像素上没有前景响应，类型分支却已经“看见”它们；语言侧融合、后处理找回、损失重加权
（3 种子）、真实外观移植、标签自洽的上下文内合成都未能撼动检测。这一缺陷与“NP 头在
40$\times$ 下的分辨率/架构不足”的假设相吻合；该假设尚未经架构层面的检验（例如提高前景
监督的分辨率），是主要的开放方向。

\paragraph{评测方法论。}三条教训，每一条都有证据支撑：(1) PanNuke 的种子噪声依赖类别（mPQ 0.002 vs
Dead 0.007），且验证折的 Dead 信号可能与测试相反（CP1：$+0.024$ vs $-0.031$）——单种子、
单折的 Dead 结论不可信；(2) 已发布的评测配方可能内嵌相当于约 0.02 mPQ 的测试侧调参收益
（我们的 HoVer-NeXt-T 解码研究），比排行榜上的典型名次差距还大；(3) 生成的评测数据系统
性地\emph{更易分割}但\emph{类型一致性更差}，因此反事实基准必须以干预臂对 control 的方式
评分，并同时报告 strict mPQ 与 mPQ。

\paragraph{Dead 作为跨域现象。}尽管 Dead 是 CONCH 文本上最可识别的类，也是域内模型检出
后能以 0.69 正确分类的类，三架构在 PUMA 上的 Dead PQ 却跌至 0.002--0.033（域内
0.13--0.18）——这说明域内的
Dead 线索（40$\times$ 下的深色固缩染色质）迁移不到黑色素瘤 H\&E 中的凋亡小体。任何针对
Dead 的改进都必须经过跨域验证，而不能只在 PanNuke 折上验证。

\section{状态与后续工作}
\label{sec:status}

所有预注册实验已完成：基线复现（课程要求 (a)(b)）与错误分解、类$\times$组织分析（课程
要求 (c)）均已完成；支柱 A/B 以负结果收官，支柱 C 以一个机理性的评测结果收官。最终报告
还需要：三架构的组织$\times$类热力图与错误分解图、一套精简的主表、可选的额外外部集
（MoNuSeg、NuInsSeg；仅 bPQ/AJI），以及文字润色。可选的开放方向（未预注册）：从架构侧
着手解决 Dead 检测缺陷，以及布局干预的反事实——用于探测仅外观 CF 无法触及的检测轴。
