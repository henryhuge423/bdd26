# Numbers and image sources / 数值与图像来源

P27–P30 use the independently verified analysis files in `evidence/p27_analysis.json`, `p28_analysis.json`, `p29_verified_analysis.json`, and `p30_verified_analysis.json`. Each contains the same-round control and intervention, both seeds, training/development aggregates, the frozen paired evaluation and configuration identity. The object-level comparisons are in `evidence/p27_fixed_objects.csv` through `p30_fixed_objects.csv`. The matched count changes in `evidence/stage_pairs.csv` are intervention minus the same-round control; the native PGFPlots figure uses those ten rows.

P31 consists of control C and group-normalization G, seeds 19 and 1. Array 55792463 completed all four tasks with 130 epochs and exit code 0. `evidence/p31_files/` contains the retained evaluation and training records, manifests, and fixed-image coordinates and selected original PNGs. Ninety-two small original payloads were checked against the preservation manifests on LM1; the subset used here is retained. `verify_numbers.py` independently checks the retained files, 522-image evaluation counts and selected point matches within three pixels.

Images in `assets/p27_image_*` through `assets/p30_image_*` are the previously verified analysis figures from `docs/results/p27_p28_2026-11-12`, `p28_p29_2026-11-14`, `p29_p30_2026-11-15`, and `p30_p31_2026-11-16`. P31 images were reconstructed from the first (original-image) panel of saved final PNGs, the annotated nuclei, the decoded points and the `unique_pairs` in the corresponding coordinate records; colors represent paired object states. The image IDs, indices and row-column positions remain in those records. All data are repeated fold-1 development comparisons using each round's last checkpoint.
