- `scripts/dsb_gradient_probe.py` 原先直接使用命令行 `--fold`，并把配置 split 写死为 1，没有调用开发折防护。现从 run 的 `config.json` 读取 split，在模型/权重/数据加载前拒绝该 split 的测试折。

## 3. E0：从同一冻结测量恢复图像加权成本

旧输出保存了 `img_per_s = 总图像数 / 总秒数`，因此不需要重新运行 GPU，即可独立恢复正确图像加权均值：

`mean_ms = 1000 / img_per_s`

按原“最高吞吐 rep”规则重新选择 rep 后，x1 选第一个 rep（而不是旧 chunk-mean 选择的第二个）。

| 指标 | 历史分块等权估计 | 图像加权修正 |
|---|---:|---:|
| x1 最佳 mean ms/image | 15.500246 | 15.506464 |
| x2-du2 最佳 mean ms/image | 52.875984 | 52.870378 |
| x1-TTA 最佳 mean ms/image | 72.332384 | 72.309163 |
| 两模型 + CPU 融合 / x1 | 6.086869 | **6.084468** |
| x1-TTA / x1 | 4.666531 | **4.663162** |

融合 wall 均值仍为 25.971742 ms/image。**没有新的性能测量，部署判断不变。** 修正数字和来源 SHA-256 记录在 [成本审计快照](results/inference_cost_audit_20261009.json)。`cost.json`、阶段四旧快照及旧 PDF 全部保留。

限制不变：共享设备负载、各臂非同时计时、不同 rep 数、分块启动开销；M/S 的 CPU 时间未单独计入。Gate B 也仅测已训练基座检查点上的分组 NP-CE + TP-CE + HV-MSE 代理损失，不能据此推断整个训练历程或完整训练目标从不存在梯度冲突。预注册止损可以成立，但机制外推必须保持该边界。

成本修正的只读复现命令：

```bash
python - <<'PY'
import json
from pathlib import Path
c = json.loads(Path('runs/analysis/inference_cost_20261008/cost.json').read_text())
best = {arm: min(1000 / r['img_per_s'] for r in spec['reps'])
        for arm, spec in c['arms'].items()}
fuse = min(r['wall']['mean_ms'] for r in c['fusion']['reps'])
print(best)
print('two-model/x1:', (best['x1'] + best['x2_du2'] + fuse) / best['x1'])
print('TTA/x1:', best['x1_tta'] / best['x1'])
PY
```
