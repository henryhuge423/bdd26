## 1. 为什么"从零"是合理下一步，以及硬约束

**依据**：证据一致指向"任务表述 + 解码结构"是主要杠杆，而现有三分支（NP/HV/TP）+ 分水岭范式有两处结构性弱点在证据中反复出现：(i) HV 只提供相邻核的分离信号，对小对象（<30 工作像素被清零）与苍白低对比对象没有召回信号，漏检后没有任何下游补救；(ii) NP 二值前景把"真实小核 / 截断残片 / 碎裂碎片"输出成同一形式，训练监督未显式表述可见性与对象单位（E4/路线 A 的原始假设）；(iii) 实例分离依赖逐像素距离场 + 分水岭，对同类密簇（karyorrhexis）是已知最弱点。

**要求清单（新模型的验收前提）**
- R1 Dead/小对象召回：主端点 = 内部 Dead recall + Uterus-excluded Dead PQ（多 split×多种子），strict Dead 不退化；
- R2 同类粘连分离：merge 率与 split 率不升（Colon/Lung 分层披露）；
- R3 分型：预测轮廓上的 matched typing 不退化；对 Inf/Conn 模糊的处理（层次/软标签/合并辅助头等）必须单列机制证据，不得靠官方缺类规则掩盖误报；
- R4 单遍成本 ≤ ~2× x1（对照 6.09× 双模型 / 4.67× TTA 的既有结论）；
- R5 协议：per-fold 自训权重、last checkpoint、官方 evaluator；泄漏清单（CellViT 官方、NuLite、HoVer-Net 官方、Cellpose-SAM、LSP-DETR、CellNuc-DETR、BiomedParse v1 等）不得作为测试结果；
- R6 对照文化：与基线、crop-only、同参数普通 adapter、低维逻辑回归等强对照同台；预注册门先行；
- R7 工程：新轮训练需先补增强 worker 状态检查点（现引擎无断点续训，冻结轮次不可改动）；存储预算先行。

**明确不做**：不重开已关闭路线；不用测试折做任何选择；不宣称未经同协议复现的 SOTA；不以"新范式"名义跳过对照与预注册。

### 2.1 非 HoVerNet 架构范式（2026-10-14 核验）

**已核实的官方 3 折非 HoVerNet 结果（全部作者自报）**
- **PromptNucSeg**（ECCV'24, 2311.15939）：网格锚点 prompter（匈牙利匹配）→ 每核一个点提示 → 微调 SAM；类别来自 prompter；K 近邻负提示处理粘连簇。官方 3 折 **mPQ .5123 / bPQ .6924，Dead PQ .161、Dead F1 .46（已知最好）**；按折权重公开（OneDrive）。oracle 提示 vs 实际提示 .790 vs .733 PQ → **提示质量是 F1→PQ 转换的瓶颈**。
- **CFR-SAM**（MedIA 112 (2026) 104144 / 2603.28027）：冻结 SAM-B + adapter；阶段 1 prompter 出质心点提示；**分类只来自阶段 1、SAM 阶段仅二值掩码**。官方 3 折 5 次重复 **mPQ .5115±.0003 / bPQ .6956±.0004，Dead PQ .153、Dead F1 45%**；点提示优于框（.5046 vs .4804）。自述限制：密集区提示错误 → 合并/漏分裂；**离散提示选择阻断 prompter 梯度**。无代码/权重。
- **LSP-DETR**（CMPB 287 (2026) 109614 / 2601.03163）：一对一二分匹配集合预测、星凸多边形（64 射线）+ **径向区间损失（重叠无需重叠标签）**、Swin-V2-T + 滑窗线性注意力、45M 参数；推理无分水岭（仅评分时 watershed）。官方 3 折 **mPQ 48.2 / bPQ 67.5**（原始口径），Dead PQ 13.0 / F1 47.4；0.45 s/mm²（比 StarDist 快 3.2×）；代码 MIT。自诊断：**DETR 逐批损失归一化（micro vs macro）对稀有类有偏**，提出密度感知损失。HF 权重是单一类无关预训练、非按折 → 不可作测试结果。
- **NuNext**（2603.07098）：Qwen2.5-VL-3B 自回归"下一个点"检测 + GRPO（PQ 作奖励）；**folds 1+2→3 非标准协议**，mPQ .5294 / bPQ .7087、Necrosis PQ .159；无代码。其表格显示**提示在核内的位置影响 PQ**（F1→PQ 转换问题）。
- **CellNuc-DETR**（2502.06307）：Deformable DETR 检测器（无掩码）；检测 F1 .84、**未报 PQ**；权重用 80% PanNuke 跨折抽样（泄漏式）。
- **PanopMamba**（2601.16631）：首个 Mamba 编码 + Mask2Former 式掩码解码；MoNuSAC 自定指标 PQ 73.11 vs Mask2Former 39.76、稀有类 macrophage 58.28 vs 14.67；**非 PanNuke**；提出 iPQ/wPQ/fwPQ 频率加权 PQ。

**负面与空白核查（对选型同样重要）**
- **Mask2Former/OneFormer/PanopticSegFormer/MP-Former 在核任务上普遍远差**（PanopMamba 同协议对比）；**Mask2Former 式掩码分类与一对多辅助查询（Group-DETR/Co-DETR 式）在 PanNuke 上零专门论文——真实空白**（空白既是新颖性也是风险）。
- SAM3 病理评测（2604.18225）：文本提示在核上失败（PanNuke mIoU 0.26–6.22），非即插即用。
- Cellpose-SAM：流场解码、无 PanNuke 数字；μSAM（Nat Methods 2025）：中心距离 + 边界距离 + 前景，距离用 Dice 损失优于 L2。
- InstanSeg：嵌入解码（种子头 → 位置嵌入偏移 → 逐种子概率图、union 合并），偏移不受图像维数约束、利于拥挤实例；后处理快 23×；无 PanNuke PQ。
- **2026-09-28 至 10-15 无新的官方 3 折 PanNuke SOTA 出现**；可验证前沿仍是 PromptNucSeg .5123 / CFR-SAM .5115；**无任何可验证 Dead PQ > .185**。
- 新增旁证：2609.35203（09-28，UNI2-h→ConvNeXt-T 蒸馏、HoVerNet 式）自报 mPQ .524/.519、**Dead F1 .49（逆频采样 + focal）** [协议未核实、无代码]；SAFViT Dead F1 .518（+14.5）[折数口径不一致]；2610.07711（10-06）肾病理微调中 LSP-DETR F1 .8725 最好；2610.13780（10-09）荧光极稀有死细胞检测基准——Dead 召回是公开难题，且尚无 H&E 上的可验证解法。

**三路证据对主设计的收敛**
- 点提示 + SAM 家族 Dead F1 最好（.45–.46），瓶颈 = 提示质量（oracle .790 vs 实际 .733）与"分类只在阶段 1"的割裂；
- 集合预测（LSP-DETR）已在官方折验证（48.2 mPQ、无分水岭、重叠/截断宽容），但稀有类受 micro 归一化之害；
- **一对多辅助查询 + 门控融合 + 逆频采样/focal + 可微提示** 是尚未在核上组合过的、逐项有依据的补丁集。

**PFM-DenseBench（2602.03887）的可迁移结论**：(1) CNN adapter 常是最优适配方式（细粒度集尤其）；(2) **LoRA 秩缩放无增益——瓶颈是冻结表征的粒度而非 adapter 容量**；(3) **输入分辨率是首要驱动**：冻结 UNI 在 TNBC 上 mIoU .620 (256) → .723 (512) → .753 (1024)，1024 后饱和（无泄漏分析）。

**高分辨率适配（小核问题的正解）**
- **CellVTA（2504.00784）**：ViT-Adapter 式 CNN adapter（空间先验模块 + 4 个交叉注意力注入器，冻结 UNI）→ PanNuke 3 折 mPQ **.506**、**Dead PQ .185（已知最好）**；对比 CellViT-UNI .179、CellViT-SAM-L .146、PointNu-Net .136——**移动小核/Dead 类的是 adapter**。负面：多尺度门控卷积（MALA）在 ViT 编码器上无增益（2609.35203 [未核实细节]）→ 选交叉注意力注入而非门控卷积。
- **ViT-Adapter（2205.08534）** 是通用机制，CellVTA 是其在病理上的实例化。
- **蒸馏到高分辨率 CNN**：UNI2-h → ConvNeXt-T（34.7M，mPQ .519 = 教师 98.8%，634 img/s，21.8× 加速；2609.35203）。
- **CRAFT（2609.18578）**：区域自适应混合尺度 tokenization，22M；**DaX（2606.06983）**：DINOv3 初始化 + 多输入尺寸 + Gram 锚定稠密一致性（最具尺度感知的新 PFM，权重 [未核实]）；Mamba 系（PanopMamba/CellMamba/HSMLA）仅探索级，无 PanNuke SOTA 证据。
- **冻结 token 足够做小目标检测**（2607.28007）：冻结 PFM token → 2D 特征金字塔（stride 7/14/28/56/112）+ RetinaNet/Faster-RCNN/DETR，H-optimus-0/Virchow 与端到端 ResNet50 竞争——对"点/检测头 + 冻结骨干"路线是正面旁证。

**SAM 系骨干（2026 状态）**
- **SAM v1（SA-1B 预训练，零病理泄漏）**：PromptNucSeg（2311.15939v4）= 微调 SAM-B/L/H + 学习式 prompter，官方 3 折 **bPQ .6924 / mPQ .5123（当前 SOTA）**，Dead .161；输入缩到 256；PromptNucSeg-B 145.6M、**59G MACs、27 FPS**（对比 CellViT-B 142.9M/232G/20 FPS——**约 1/4 计算量**）；Prompt-free LoRA-SAM（2603.20326）：4.1M 可训练参数，TNBC/MoNuSeg/PanNuke 自报 SOTA。
- **SAM3（2511.16719）**：病理评测（2604.18225）文本提示难以激活核概念、视觉提示脆弱、少样本仍落后任务训练 adapter——**非即插即用**。SAM2 病理使用都在组织级，无核 SOTA。

**单遍多尺度策略（对 6.09× 双模型成本的替代）**
- DenseBench 路线：**训练 256、推理 512–1024 单遍**（CellViT++ 实践）。
- 可提示式：一次 256 编码 + 批量逐核提示解码（PromptNucSeg 以 1/4 MACs 达到 SOTA）。
- Adapter：全阶段单遍多尺度注入（CellVTA）。
- 蒸馏高分辨率 CNN 学生（ConvNeXt-T）：单遍 634 img/s。

**对新模型骨干的排序建议**
1. **UNI2-h + CellVTA 式 ViT-Adapter 交叉注意力注入**（最佳泄漏干净稠密骨干 + 唯一被证明移动 Dead PQ 的适配机制；训练 256、推理单遍 512）。
2. **SAM v1 ViT-H + 学习式 prompter（PromptNucSeg 式重训）**：SOTA .512 + 零泄漏 + 约 1/4 计算；工程成本更高（提示解码、重叠处理）。
3. **蒸馏高分辨率 CNN 学生（ConvNeXt-T）**：延迟优先时的单遍选择；Dead 类预期有差距。
- 备选骨干：H-optimus-0（Apache-2.0 最宽松）/ Virchow（MSKCC）。
### 2.3 稀有类、标签模糊与分子监督（2026-10-14 核验）

**稀有类/Dead 检测**
- **SAFViT**（arXiv 2607.27835，CMIG 2026）：把 CellViT 的跳跃连接换成通道 softmax 门控（逐像素"信任热图"），**不加类重加权/重采样，Dead F1 .373→.518（+14.5 点）**；自报 mPQ .471 vs 其 CellViT 复跑 .453（其复跑基线低于本项目 .4995，折数口径论文内不一致，引用需注明）；代码公开、无权重。→ 证据：**解码器多尺度融合的门控可以大幅移动稀有类 F1**，是 2025–26 已核实的最大架构级 Dead 增益。
- **LSP-DETR**（arXiv 2601.03163 v2 2026-09-09，CMPB 287:109614）：星凸多边形 + 线性复杂度 DETR，**径向距离损失显式容纳标注不确定性**，无启发式后处理；bPQ .675、对双病理学家共识 F1 .964、0.45 s/mm²（比 StarDist 快 3.2×）；代码公开（RationAI/lsp-detr）；发布权重为全量训练（泄漏，不可作测试结果）。
- **CellDETR**（arXiv 2606.29463）：Deformable-DETR + 位置-特征解耦 + 框约束注意力，**用 Xenium 派生标注预训练**；摘要级声明 PanNuke 有监督分类 SOTA [未核实，无数字]。
- **Apoptosis-as-anomaly**（arXiv 2602.02124）：LoRA-DINOv2 + 类条件 Mahalanobis 阈值，把凋亡当近 OOD 处理（鼠肝 WSI）。
- **负面核查**：2025–26 没有找到"重加权/重采样在稀有核类上复现增益"的论文；已核实的增益都来自架构（SAFViT）或不确定性感知损失（LSP-DETR）。本项目 M1/C1/M2 负结果与文献一致。

**标签模糊**
- **Gleason 软标签**（arXiv 2410.15012）：54 名病理学家描述作为软标签，捕捉内在不确定性，优于硬 GT（Dice .713±.003）——"标注者分歧软目标"的最强直接证据。
- **层次保持对比学习**（arXiv 2511.03771）：把标签树作为训练信号（层次加权对比 + 层级 margin），含乳腺病理。
- **Prompt-based Grouping Transformer**（arXiv 2310.14176）：核嵌入的层次分组（组嵌入作 prompt），核检测+分类。
- **PhenoBench**（arXiv 2507.03532）：14 细类 H&E 基准，FM 在 Lizard/PanNuke >.70 macro-F1，在 PhenoCell 低至 .20——细粒度分类法的量化代价，支持"粗父节点（Inf+Conn 合并）"头。
- **PanNuke 标签重映射**（arXiv 2502.19217）：PanNuke+MoNuSAC 统一为 7 类分类法，冻结 H-Optimus 蒸馏——唯一直接重映射 PanNuke 标签的 2025 工作。
- **负面核查**：没有找到显式处理 PanNuke Inf/Conn 边界的论文；最近证据 = PhenoBench 粒度代价 + Gleason 软标签 + LSP-DETR 不确定性损失。

**分子/空间监督**
- **CytoFormer**（arXiv 2608.16718）：Xenium 监督的细胞 FM（81 对切片、15.4M 细胞、23 型、per-organ 头）；**PanNuke 线性探针 79.3 vs MUSK 70.3（p<.001）**，逐类 neoplastic 89.7 / epithelial 87.1 / connective 76.7 / **inflammatory 64.8 vs 52.8**；代码+权重公开（zhihuanglab）。**其 PanNuke 评估为 4 类、无 Dead 监督**——Inf/Conn 模糊恰好是其增益最大处。
- **CellPath-Bench**（arXiv 2608.21060）：25 对 H&E-Xenium、11 器官、7M+ 细胞，核锚定的 FM 表征评测 + 跨切片/器官迁移。
- **STHELAR**（HF FelicieGS，cc-by-4.0）：Xenium+H&E 配对、细胞类型 + 掩码，已核验存在。
- **GigaTIME-Flash**（arXiv 2607.18218）：ViT-S 22M，从 H&E 预测 21 通道 mIF，面板含"增殖与凋亡标志物"；**Caspase-3 未在可及文本中具名 [未核实]**；Apache-2.0 权重公开。→ Dead 唯一可能的"分子辅助监督"来源，须先确认通道面板。
- 2026 单细胞监督：CELLO（2609.36429，NeurIPS'26）、VOICE（2608.08366）、STORM（2604.03630）。

**多数据集与生成**
- 再次核实：**没有 2025–26 工作在官方 PanNuke 上靠多数据集训练获得增益**；最好官方数字仍是单数据集（.519 蒸馏 2609.35203 / .506 CellVTA / .471 SAFViT）。多数据集只对迁移/鲁棒性有理由。
- **PRISM**（arXiv 2609.05028）：奖励模型 + 分层约束 RL 微调 mask+text 条件扩散，PanNuke 下游 +2.3% mDice——相对本项目 PixCell 零结果的 2026 增量在"奖励模型微调"而非新条件方案。
- μSAM 基准（arXiv 2603.17845）：**自动提示生成（APG）稳定改善 μSAM、与 Cellpose-SAM 竞争——提示工程胜过架构调优**（对点范式是正面旁证）。
## 3. 候选架构设计

### 3.1 设计逻辑（从证据到模块）

| 证据 | 设计要求 | 候选模块 |
|---|---|---|
| Dead 漏检是召回问题（38.5% max-IoU<.1；oracle +.156）；漏检含孤立小核、苍白凋亡体、碎裂块 | 检测信号独立于点状外观假设；点/中心级监督比掩码 IoU 匹配宽容 | 类感知点热图辅助头（stride 2–4），focal + 小对象友好分配 |
| SAFViT（2607.27835）：门控多尺度融合使 Dead F1 +14.5，**无需类重加权** | 多尺度融合要可学习地门控（逐像素信任），而非固定相加 | 通道 softmax 门控融合块（解码器内） |
| 同类密簇 merge（Colon .089；karyorrhexis 73–82% 同类接触） | 实例分离信号须在同类低对比处工作；避免仅距离场+分水岭 | 查询式掩码解码（一对一二分匹配）或点条件化动态卷积掩码头 |
| 点提示+SAM 家族 Dead F1 .45–.46 最好；DETR 家族 F1 .46–.47 但 PQ 仅 .130 | 检测（点）与掩码质量解耦：点负责召回，掩码头在 stride-2/4 局部特征上生成 | 共享编码器 + 局部（ROI 式）掩码解码，单遍 |
| LSP-DETR（2601.03163）：径向距离损失显式容纳标注不确定性，星凸多边形参数化，代码公开 | 边界参数化要能表达"不确定/被截断"的轮廓，而非二值逐像素硬标签 | 星凸多边形径向回归头（备选或并列掩码参数化） |
| LSP-DETR 官方折已验证集合预测（48.2 mPQ、推理无分水岭、重叠宽容）；自诊断 DETR micro 归一化对稀有类有偏 | 稀有类需宏平均/密度感知损失；一对多辅助查询加密监督（核上零先例） | 一对多辅助查询 + 逆频采样/focal + 密度感知损失 |
| E4：截断→漏检因果证据；可见性轮在检验 HV 机制 | 可见性/截断状态要显式监督或显式输出 | 截断标志辅助任务 + 可见掩码一致性目标 |
| Inf/Conn 模糊（E1-T 72.5% 共鸣；M 合并 +.0519；CytoFormer 增益最大在 inflammatory） | 分型不假设 5 类边界锐利；软标签/层次有文献先例 | 层次辅助头（5 类 + 合并父节点）+ 可选 jury 软标签蒸馏 |
| 分类 oracle .6632 vs 现状 .4995；T0–T3 冻结特征读出负 | 分型信息可能需联合几何训练进入特征 | 实例级分类头（掩码池化 + 固定上下文），与检测/掩码联合训练 |
| 单遍成本 ≤2× x1（对照 6.09×/4.67×） | 不允许双模型/双尺度推理 | stride-4/8 CNN adapter；单遍 512 或 256+adapter，预算核对 |

### 3.2 推荐主设计：单遍"点查询 + 门控融合 + 掩码/多边形解码"（工作名 PM-Net）

- **骨干**：**UNI2-h + ViT-Adapter 式交叉注意力注入**（CellVTA 配方；泄漏干净、PFM-DenseBench PanNuke 稠密最佳；交叉注意力注入优于门控卷积）。备选：H-optimus-0（Apache-2.0 最宽松）/ Virchow / 现基线 UNI（已集成，回退选项）。
- **像素解码器**：多尺度特征金字塔 + **通道 softmax 门控融合**（SAFViT 教训），输出 stride-4 高分辨率特征。
- **检测支路（召回优先）**：类感知中心热图（stride 4），focal loss；峰值初始化 K≈256 实例查询（或直接点监督 + 匈牙利匹配）。显式承载 Dead 召回目标；类可以是"先类无关、再分型"（对照臂）。
- **实例解码**：查询在 stride-4 特征上做变形注意力；掩码参数化三选一（实现时冻结其一做主臂，其余做消融）：
  - (a) 动态卷积掩码头：每实例在局部窗口生成 mask logits；
  - (b) 星凸多边形径向回归（LSP-DETR 式）：对截断/模糊边界更宽容，且天然给"轮廓外延"能力；
  - (c) SAM v1 式提示掩码解码器（PromptNucSeg 直系，SA-1B 零病理泄漏）：以点/查询作提示、批量逐核解码——已验证 .5123 mPQ 且约 1/4 MACs。
- **稀有类偏置修正**（LSP-DETR 自诊断 + 蒸馏线证据）：匹配/损失按宏平均或密度感知归一化；逆频采样 + focal（2609.35203 的 Dead F1 .49 配方）作为标准配置。
- **一对多辅助查询**（核上空白，需预注册）：训练期附加 one-to-many 查询分支加密正样本监督（Group-DETR/Co-DETR 式），推理只用一对一分支。
- 若选 (c) SAM 式解码：**提示选择必须可微/软**（修 CFR-SAM 的梯度阻断），**分类头必须与掩码联合**（修"分类只在阶段 1"的割裂）——两点都是文献已定位的具体缺陷。
- **分型头**：实例掩码池化 + 固定宽度上下文 → 5 类头；**并行 4 类合并父节点头**（层次损失，小权重），官方指标仍按 5 类报告；可选把 12 席 jury 分布做软标签蒸馏（Gleason 软标签先例）。
- **可见性辅助**：截断标志二分类 + 训练时可见掩码一致性目标（与可见性轮 A2 构造对齐）。
- **解码**：无 HV、无分水岭；输出实例掩码直接进官方 evaluator；小面积过滤沿用 30 工作像素保持可比。
- **分辨率与成本**：训练 256、**推理单遍 512**（PFM-DenseBench：分辨率是首要驱动 .620→.723→.753 单调；单遍 512 实测约 3.1–3.4× x1，仍远低于 6.09× 双模型）；若超预算则 256 单遍 + adapter 全阶段注入。成本目标（≤2× x1 或 ≤3.5×，实现前冻结其一）。

### 3.3 备选设计（按优先级）

- **B1：纯查询式全景分割（Mask2Former 式掩码分类）**——去掉点热图支路的最简版；风险是小对象掩码质量与 DETR 家族 F1→PQ 转换前科；PanopMamba 同协议下 Mask2Former 远差于 Mamba+掩码解码，且 PanNuke 上零论文——空白即风险。
- **B2：稠密嵌入 + 聚类解码（InstanSeg 式）**——最简实现、低成本对照。
- **B3：星凸多边形 DETR（LSP-DETR 配方直系）**——代码现成（RationAI/lsp-detr），作为"不确定性边界"的独立对照臂；其权重泄漏不可用于测试。
- **B0：SAM v1 + 学习式 prompter（PromptNucSeg 直系重训）**——已验证官方 3 折 SOTA .5123/bPQ .6924 且零病理泄漏、约 1/4 MACs；若主设计的自研解码在第一轮 dev 不占优，此线作为替代实现路径（工程成本：提示解码与重叠处理）。
- **B4（扩展）：CytoFormer 初始化/蒸馏**——Xenium 监督的表征作分型教师（其 4 类无 Dead，Dead 另寻信号）；仅在 P3 通过后立项。

### 3.4 与"HoVerNet 类结构"的明确切割

不再使用：NP/HV/TP 三分支、HV 距离图、分水岭实例解码、min_size=30 的 HV 清零语义。
保留可复用资产：UNI 编码器加载路径、数据管线、官方 evaluator、错误分解、bootstrap 统计、预注册流程。

## 4. 监督与训练策略

- **稀有类**：不做像素重加权（M1 负，且文献核实 2025–26 无复现增益）；Dead 召回交给点热图支路 + 训练内 OOF 失败挖掘难例采样（点级权重机制不同，单列对照）。
- **标签模糊**：默认 5 类 CE；合并父节点辅助头（Inf+Conn，先例 2310.14176、PhenoBench 粒度代价）；可选软标签：以 12 席 jury 分布做软交叉熵（Gleason 先例 2410.15012），机制端点 = matched typing 与 strict，不追求官方 mPQ 数值本身。
- **可见性**：与可见性轮冻结的 A2 构造对齐（裁剪身份追踪 + 可见掩码）；A2 门通过则纳入新模型规格，失败则保留截断标志作独立假设。
- **分子教师（条件性）**：GigaTIME-Flash 凋亡通道（**Caspase-3 未核实**，先验证通道面板）作 Dead 辅助监督试点；CytoFormer 作 Inf/Conn 分型教师候选（4 类、无 Dead）。两者均为 P4 扩展，不进主臂。
- **增强/日程**：沿用现行配方（130epoch、unfreeze25、lr 3e-4、gamma .85）作第一轮匹配条件；日程对照后置（10-06 §2.5 混杂未排除）。
- **训练工程**：新轮启动前补增强 worker 状态检查点（现引擎无断点续训）；config/输入哈希绑定；磁盘预算先行。
## 5. 评测、预注册门与对照

- **协议**：官方三划分、per-fold 自训、last checkpoint、官方 evaluator（bit-exact 管线复用）；测试折仅在最终确认轮读取一次。
- **主端点（建议，最终以规格冻结）**：内部 Dead recall（+）、**Dead F1（与文献可比口径，当前可验证前沿 .46）**、Uterus-excluded Dead PQ（+）、merge 率（不升）、official mPQ（≥−.002 护栏）、strict mPQ（不降）、单遍推理成本（成本目标实现前冻结）。
- **机制端点**：点热图对内部 Dead 的召回分解；密簇 merge/split 计数；截断对象的可见掩码一致性；Inf/Conn 混淆矩阵与层次头校准。
- **可选补充口径**：PanopMamba 的 iPQ/wPQ/fwPQ 频率加权 PQ 作稀有类敏感诊断列（官方指标仍为主端点，不替换）。
- **强制对照**：现基线（同配方重训）；同参数普通 adapter 对照（证明不是"更大的头"）；crop-only 增强对照；低维逻辑回归（证明学习模块必要）；成本对照（x1-TTA、EF-P2 冻结结果）。
- **dev 规模**：fold1→fold2，1–2 种子先导；门通过才三划分确认（新立项）。

## 7. 风险、证伪条件与停止规则

- 点范式若在 P1 探针就无召回优势 → 停止，不进入训练（对应 KongNet 教训的廉价前置版）。
- 若收益只出现在训练裁剪分布、自然边缘/外部集无迁移 → 按路线 A 止损规则停止。
- 若合并辅助头只改变官方缺类规则下的数值而 strict 恶化 → 判失败。
- 若单遍成本超 2× x1 且无端点补偿 → 判失败（EF-P2 的成本教训）。
- 复现风险：新架构的调参面更大，必须用同配方、同种子、同 evaluator 的成对比较，避免"新架构+新配方"混淆。
- 主要不确定性：查询/点式方法在小对象 IoU 匹配下的掩码质量（DETR 前科）；PanNuke 单图对象数上限对查询数的压力。
