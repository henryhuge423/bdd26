## 2. 检测优先 vs 稠密头（Dead 的架构证据）

Dead F1（HoVer-Net 定义，质心 12 px）：

| 架构族 | 代表 | Dead F1 |
|---|---|---|
| 稠密 ViT/16 头 | CellViT-SAM-H | .36 |
| 稠密头（我们，严格解码 3 折 Dead F_c） | CellViT-UNI .359 / HoVer-NeXt-T .349 / HoVer-Net .230 | .23–.36 |
| 点提示 + SAM | PromptNucSeg .46 / CFR-SAM .45 | .45–.46 |
| 逐类质心热图（CNN） | KongNet（EfficientNetV2-L） | **.59** [论文自报] |
| DETR 集合预测 | CellNuc-DETR .46 / LSP-DETR .47 | .46–.47 |

- **解码敏感性**：HoVer-NeXt 论文 Dead F1 .49 来自测试折调阈值 + 16 次随机颜色 TTA；我们 val 调参解码下只有 .35。任何"Dead 提升"须先过严格协议。
- **F1 增益未转化为 PQ**（LSP-DETR F1 .47 → Dead PQ .130）：官方 PQ 要求 IoU>.5 的掩码匹配 + 逐图子集平均；检测增益要变成 PQ 还需点条件化的掩码级（SAM 解码器 / 检测作 watershed 种子）。
- **分辨率证据**：CellViT 在 0.5 µm/px 重训重测 Dead PQ .149→.031（R .32→.04）；CellNuc-DETR 在 0.5 µm/px 仍 .42；PFN-DenseBench 输入 256→512→1024 mDice .732→.823→.846（1024 后饱和）。**无人做过官方协议下的 >原生分辨率（2× 上采样）消融——最直接的假设检验。**
- 增广是最强单项（CellViT256 Raw→Aug Dead PQ .067→.156）——我们已有。

## 6. 多模态 / 通用模型（对我们项目）

- **VLM 文本塔在稠密任务无优势**（PFM-DenseBench：CONCH .518 vs 最好 .539；MUSK 最差 .380）——与我们 CONCH 重分型阴性结果一致。
- **MLLM 做单核分类≈猜多数类**（PathView-Bench 2607.28318：框选单物体分类 ≤.30 vs 多数类 .213；计数 MAE 17–83）。不要用 MLLM 审单核标签。唯一核级正面结果 NuNext（Qwen2.5-VL 出质心 + RL(PQ) + SAM，代码未放出）→ MLLM 当**检测器**而非分类器是可行方向。
- **分子监督改善非 Dead 分型**：CytoFormer（2608.16718，15.4M Xenium 细胞）PanNuke 4 类 linear probe F1 79.3 vs 70.3（其去掉 Dead，且 fine-tune 在测试 F1 上早停 [未核实协议]）；MIPHEI-ViT zero-shot typing .60 vs ROSIE .40。
- **结论：多模态落点 = 分子标签**（Caspase-3 试点 → 独立凋亡教师信号做伪标签/验证）**+ 语言仅作多数据集标签粘合**；文本重分型已证伪，不再投入。

## 7. 生成模型 / 鲁棒性评测（支柱 B/C 后续）

- **无公开 40× 类条件（含 Dead）生成器**：PixCell 无类条件变体（查过 StonyBrook HF org）；Co-synthesis / Oh&Jeong / PathDiff 用 PanNuke 随机 80/20（泄漏）且无 Dead 指标；HistoSmith 20×；NucleiMix 是"贴真实核 + inpainting"（非纯合成）。
- **合成收益在分类不在检测**（DiffMix Misc F1 +15.9 vs DQ +2.2；HistoSmith 中性粒 DQ +9.6 但 class-agnostic recall 持平 80.4→80.2 → 实为分型增益）。唯一有检测增益证据的是贴真实实例（X-Paste/DiverGen，自然图像）——我们 CP1 已试，Dead 受损。MIDOG'25 稀有非典型有丝分裂合成亦无一致增益（2509.02612）。
- **检测轴的真实域偏移数据**：PLISM-wsi（Sci Data 11:330, 2024；46 组织 × 13 染色 × **7 扫描仪**，连续切片配准 512px 40× tile；**无核标注** → 在一台扫描仪上标注、经配准迁移即可得"标签固定的真实扫描仪偏移"测试；Owkin HF 副本仅 20×）；MIDOG'21 跨扫描仪核分裂 F1 .683→.325。这是我们 CF 检测轴盲区的现实补法。
- 组织病理"世界模型"仍不存在（只有位置论文与培养细胞药物扰动模拟器）→ 报告继续用"反事实渲染器/可控生成模拟器"措辞。
