# 合并类分型模糊度量诊断（M 实验）设计 spec

起草 2026-10-13｜状态：**待用户批准，未启动。** 依据 E1-T 检测器共鸣证据（findings 2026-10-12）
与分类 oracle 只读诊断（2026-10-09）；本实验是其**度量侧对偶**：不改任何检测结果，仅把 GT 与
预测共同的类别空间做合并重映射，量化 Inf/Conn 标签边界模糊在官方指标上的权重。诊断性实验：
**无通过/失败门，无方法主张，不产生任何可部署改动。**

## 1. 背景与动机

- E1-T：12 席跨折/跨架构 jury 对基模型分错实例投票，72.5% 支持基类 [.706,.742] vs 18.2% 支持
  真值类，本征翻票率 1.9% ⇒ Inf/Conn 标签边界模糊的检测器共鸣证据（非生物学断言）。
- 分类 oracle（GT 辅助、固定几何改类别）：三划分 mPQ .4995 → .6632；Inf/Conn 真值对象全修正
  解释约 70% 干预增益（选择条件按 GT 类别；不可相加解释）。
- 开放问题（度量侧）：把 Inf 与 Conn 合并成一个类后官方 mPQ 升多少？相对其它类对合并（机械
  效应参照）是否异常大？oracle 差距在合并空间下缩小多少？这些数字直接决定最终报告中
  "标签模糊占分型损失多大权重"的表述。

## 2. 假设与产物（描述性，无门）

**假设 M：** Inf/Conn 边界模糊在度量上表现为 (a) 合并 {Inf,Conn} 的 mPQ 增益位于全部 10 个
类对合并增益分布的顶端；(b) 合并类 PQ 明显高于原两类 PQ 的均值；(c) typing-oracle 干预增益
在合并类空间下大幅缩小。

**产物：** 预注册表 = 3 split × {M0 恒等 + 10 类对合并 ×（官方 mPQ、strict mPQ、逐类 PQ）} +
oracle-under-merge 三干预重算。全部描述性，附配对图像 bootstrap 95% CI（组织内分层，1000 次）。

## 3. 干预定义（冻结菜单，不扫描）

- **M0 恒等重评**：类空间 1..5 不变。绑定检查：3 split 的 mPQ / 逐类 PQ 与冻结 eval 产物
  逐位一致。
- **Merge(a,b)**：GT type 图与预测实例类同时重映射 a,b→min(a,b)，类空间变 4 类；官方 mPQ 的
  汇总口径同构（组织平均 × 图像 nanmean × 类平均，类数为 4）；strict 同理。
- **10 个类对全部计算**：{1,2},{1,3},{1,4},{1,5},{2,3},{2,4},{2,5},{3,4},{3,5},{4,5}；
  假设对 = {2,3}（Inf/Conn），其余 9 对为参照分布（避免事后择对）。
- **Oracle-under-merge**：`typing_oracle.py` 的 current / oracle / inf_conn 三干预在 {2,3}
  合并空间重算（oracle 相应变为"合并类空间下已匹配对象改对合并类"）。

## 4. 不变量（绑定；违反即停机修 bug，不得继续出数）

1. **bPQ 在任何合并下逐位不变**（类无关指标）。
2. **Merge(2,3) 下 Dead(4) 类 PQ 不变**（按类匹配，类 4 的 TP/FP/FN 不受 2/3 重映射影响）。
3. M0 与冻结 eval 逐位一致。

## 5. 数据与冻结输入（只读，沿 typing_oracle 先例）

- 预测：`runs/cellvit_uni/split1/pred_test_fold3.npz`、`split2/pred_test_fold3.npz`、
  `split3/pred_test_fold1.npz`（与 oracle 轮同一批产物；运行时记录 SHA256）。
- 无训练、无调参、无选择。测试产物**只读诊断**，结论措辞与 oracle 轮一致：真值辅助/重映射
  诊断，非独立测试证据，不进入任何方法成绩表。
- 脚本级 fold guard：拒绝上述三个路径之外的任何预测输入。

## 6. 实现（TDD 先行）

- `src/nucseg/metrics/merged_class.py`：类重映射的 4 类官方/strict mPQ 评估（复用
  `fast_retype` 匹配表，类轴由 NUM_CLASSES 泛化为 C）。
- 测试：(i) 恒等重映射 == 原 5 类结果；(ii) 合并重映射 vs 朴素逐图重算一致到 1e-10；
  (iii) 不变量 1/2 的合成数据测试；(iv) 官方 NaN 约定（GT 缺类 NaN；strict 记 0）与
  `pannuke_eval` 一致。
- 脚本 `scripts/merged_class_diag.py`：产出 §2 全部数字 + JSON 工件到
  `runs/analysis/merged_class_20261013/`（含 commands.md）。
- findings 条目 + 供最终报告分析框架引用的结果段。

## 7. 预算

纯 CPU；每 split 10 合并 + oracle-under-merge ≈ 分钟级，总计 <1 小时。

## 8. 风险与边界

- 合并把类平均分母 5→4——这正是要量化的机械效应，由其余 9 对的参照分布校准；**不得**把合并
  增益直接写成"模糊损失"，只表述为"合并类空间下的度量变化"。
- mPQ 非线性：oracle-under-merge 差距缩小不等于可相加的"模糊份额"；报告差值与区间，不做
  份额分解。
- 结论只支持"度量侧与 E1-T 共鸣证据一致/不一致"，不支持生物学断言，也不改变官方 5 类成绩表。
