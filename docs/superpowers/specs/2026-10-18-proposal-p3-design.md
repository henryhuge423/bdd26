## Hypothesis and comparisons

Test whether adapting a pathology encoder, rather than fitting a head to frozen features, improves inferred instance proposals on held-out images. Four matched arms: F0 (frozen, no augmentation), F1 (frozen, augmentation), T0 (trainable, no augmentation), T1 (trainable, augmentation). Seeds19/1 for all arms. Primary comparison T1−F1; T0−F0 and augmentation effects are secondary, with no winner selection. All arms use the same pretrained UNI ViT-L/16 and same randomly initialized heatmap decoder per seed. This deliberately uses UNI rather than P1's UNI2-h, so results cannot isolate the reason for differences from P1-R1.

UNI native256, layers6/12/18/24, width1024, pretrained weights SHA56ef09b44a25dc5c7eedc55551b3d47bcd17659a7a33837cf9abc9ec4e2ffb40. All dropout/drop-path zero; encoder eval mode in every arm (gradient flow remains enabled). T arms unfreeze only blocks13–24. F arms freeze everything in encoder. Per-layer LayerNorm without affine on token features, same for all arms; no fit-statistics leakage. Decoder: layerwise1x1 to192, concat→3x3conv256, three nearest2x+3x3 blocks192/128/64, final1x1 and bilinear256; ReLU, no batchnorm, output weight0/biaslog(.01/.99). No masks, typing, gate, HV or class weighting.

## Data and optimization

Phase A: fold1 only; group by tissue and presence of interiorDead; order each group by SHA256('p3-20261018:'+image_index), assign first max(1,floor(.2*n)) images to audit if n≥2, singleton remains fit. Record exact indices; image disjointness is not patient independence. All objects/classes, no area filtering. GT point is foreground pixel nearest instance centroid, row-major tie; type majority vote, border exclusion only for interiorDead endpoint. Targets max-combined radius3 sigma1 Gaussians with exact center1. Center focal loss alpha2 beta4, normalized by actual batch GT count.

130 epochs, no early stopping/checkpoint selection. AdamW head lr3e-4, encoder lr1e-5, betas(.9,.999), weight_decay.01; cosine schedule to10% initial over130epochs, global grad norm1. Microbatch4, accumulate4; final partial accumulation weighted by number of images, not by number of microbatches. BF16 autocast, FP32 parameters/loss. Seed controls initialization/shuffle; augmentation RNG separate so image order matches arms. Augmentation: uniform90-degree rotation, horizontal flip p.5, brightness gain U(.8,1.2), contrast about image spatial mean U(.8,1.2), clipped[0,1]. Transform RGB and target identically in geometry; no interpolation/crop/stain fitting or GT-conditioned augmentation. Eval native images, noTTA.

Phase A evaluates fixed fit and audit cohorts once after final checkpoint. Training losses are logged each epoch, no audit-derived adjustment. ## Pre-launch review clarifications (before new model outputs)

Matching first maximizes cardinality, then minimizes total squared distance. For exact remaining ties, use SciPy linear_sum_assignment's deterministic output on GT rows in ascending instance-ID order and candidate columns in decoder order, under the recorded pinned SciPy version. Matching never sees class/border labels. Bootstrap samples image IDs within tissue with replacement and recomputes the difference of pooled matchedDead/totalDead ratios; report percentile95%CI, not average image recalls. Gradient accumulation sums focal numerators divided by the entire effective batch's GT count (max1), including final partial groups; this supersedes the earlier image-weighting sentence. LayerNorm has no affine parameters. Fixed audit support was checked before training:522images,11interiorDead-positive images,145interiorDead objects; fit2134images. Small support remains a limitation despite meeting the floor.

Checkpoints store only trainable encoder parameters plus all decoder parameters and, for last.pth, optimizer/RNG/epoch; immutable pretrained encoder weights are SHA-bound dependencies.
