# 可见片段监督 dev 轮：冻结规格

起草：2026-10-14（美国东部时间）。状态：**用户已批准 dev 实现和启动训练**（2026-10-14 当前会话：“启动训练并继续推进”）。
目标：检验在相同裁剪增强下，为截断小片段保留 HV 目标是否能降低漏检，并避免官方指标改善伴随 strict Dead 退化。
依据：E4 修复后工件 `runs/analysis/visibility_probe_20261014/probe.json`；代码提交 `988c0cd`。

## 1. 证据与边界

E4 冻结门均通过：H1 面积分层 Dead 贴边−内部差 +.1738 [.1060,.2528]；H2 DiD +.1474 [.1392,.1557]，插值对照 −.0006；H3 碎片面积档差 +.8175 [.7968,.8393]。
这是单检查点的受控裁剪证据。窗边位置、上下文移除和放大仍共变；DiD 不能保证完全消除差异性放大效应。H3 不证明 HV 清零造成漏检，训练对照正用于检验这一假设。

## 2. 方案选择

推荐先做最小监督干预：使用裁剪前实例身份追踪和裁剪后的可见掩码构建 HV 目标，暂不增加新模型头。
单纯加强裁剪作为必要对照；新增可见性预测头会同时改变容量和目标，留待最小干预通过后考虑。
不重开已关闭的 DSB、冻结特征重分型或 E3 候选质量路线。

## 3. 冻结对照臂（当前授权覆盖四臂双种子 dev）

| 臂 | 裁剪 | HV 监督 | 目的 |
|---|---|---|---|
| A0 | 现行基线配方 | 现行 min_size=30 | 同代码重新训练的基线 |
| A1 | RandomSizedCrop 概率由 .1 提高到 .5，其余几何配方不变 | min_size=30 | 增强暴露对照 |
| A2 | 与 A1 完全一致 | 仅对裁剪导致截断且可见面积<30的对象，以可见掩码生成 min_size=1 HV 目标；其余保持30 | 截断片段目标干预 |
| A3 | 与 A1 完全一致 | 所有可见对象 min_size=1 | 全局小目标阈值对照 |

四臂共用 NP/TP 标签、网络结构、损失权重、优化器、训练日程、数据采样和解码。A2 不忽略截断实例、不补视野外标签、不提高 Dead 权重。
面积阈值30在最终训练工作坐标系计算；E4 H3的30是裁窗原生像素，两者经resize后不等价，不能混用。HV目标在全部几何变换后生成。A1/A2/A3使用相同的逐样本增强随机序列，身份追踪不得额外消耗随机数。
裁剪前完整性须随几何变换追踪；原 patch 已贴边的实例不能被误记为“此次增强新截断”。对退化单像素/单轴片段采用既有 HV 生成器合法有限的目标行为（不额外强制为零），记录计数，不能制造未定义坐标。

## 4. 数据、种子和运行阶段

- dev 仅 split1：fold1 训练、fold2 验证；fold3 禁止读取。先使用 seed19 和 seed1，四臂成对训练，共8次完整 dev 训练。
- 每臂从相同预训练初始化独立训练，不从不同实验 final 检查点继续训练。训练时长和冻结 backbone 日程逐项继承现行基线 config；完整 config 由实施计划给出并哈希绑定：130 epochs、unfreeze25、batch16、lr3e-4、weight_decay1e-4、gamma.85、sampling_gamma.85、workers8、val_every5。
- CPU 几何/标签单测与全量回归通过后执行本次授权的单次短 smoke；smoke 仅检查有限损失、梯度、实例身份和资源，不用于筛选超参数。
- 仅评估 last checkpoint；无 TTA、x1、同一解码常量。fold2 同时已用于 E4/T 等历史轮次，必须披露重复使用与 dev 结论边界。
- dev 成功仅允许提出三 split 确认轮，不自动读取测试折或启动确认训练。

## 5. 端点与拟议停止规则

主比较 A2−A1 隔离监督干预；A2−A0 判断整体实际代价；A3 用于识别结果是否只来自普遍降低阈值。
主机制端点：固定 E4 C2 窗口中新截断 Dead 的 max-IoU<.1 漏检率。原图端点：official mPQ/bPQ、Dead PQ、strict Dead PQ、内部 Dead matched rate；另报 E4 H1 面积分层差、split/merge和 matched typing。

冻结 dev 准入规则必须同时满足：

1. A2 相对 A1 两种子新截断 Dead 漏检率均下降，种子均值下降至少 .03，组织内图像聚类配对 bootstrap 95% CI 的改善下界>0。
2. A2 相对 A0 两种子 strict Dead PQ 均不下降；两种子 official mPQ/bPQ 各自变化均≥−.002，平均 Dead PQ 改善≥+.005。
3. A2 相对 A1 平均 strict Dead PQ 不下降；若 A3 与 A2 表现不可区分，仅支持“降低小对象 HV 门槛”，不得归因为可见性特定机制。

以上为本轮训练前冻结的新门，不是 E4 门；不得根据观察结果调整。两种子和图像 bootstrap 不构成独立患者或训练种子总体推断，也不构成非劣性证明。
任一准入条款失败停止，不扩菜单、不追加种子挽救。通过仍只属 dev 候选。

## 6. 验证、成本与可追溯性
