# 固定几何实例分型探针（T 实验）设计 spec

起草 2026-10-10｜状态：**待用户批准，未启动。** 依据 [RESEARCH_NEXT_2026-10-09](../../RESEARCH_NEXT_2026-10-09.md) §3
（2026-10-10 修订版）；本文件把它落成可执行、预注册的规格。任何数值在运行前冻结，运行后不放宽。

## 1. 背景与动机

分类 oracle（GT 辅助、固定几何把 IoU>0.5 已匹配对象全部改对，`typing_oracle.py`）显示官方 mPQ
.4995 → .6632 的真值辅助上限；其中 Inf/Conn 真值对象全修正解释约 70% 的干预增益（选择条件按 GT
类别，非双向混淆的孤立贡献）。已测的 CONCH 外部特征重分类为负结果。尚无答案的问题是：**当前
分割器自身的实例级特征 + 简单读出器，能否在不改几何的前提下改善分型。**

## 2. 假设、端点与判定规则

**假设 T：** 固定实例数量与轮廓时，实例级 TP 特征（及其固定宽度邻域）含有像素多数票未利用的
类别信息，简单线性读出即可测出。

**主端点：** split1/fold2（验证折）official mPQ（`RetypeEvaluator`，固定实例集合），各配置对 T0 的 Δ。

**次端点：** strict mPQ、五类 PQ（Dead 单列）、逐组织 mPQ、T0→T* 混淆矩阵与新增错分数、
matched-only 分型准确率（诊断用，不替代完整指标）。bPQ 必须逐位不变（几何固定）；若变，先查
流程，不得解释为方法效果。

**进入确认轮的判定（全部满足，缺一即不过）：**
1. 最优学习配置（T2/T3 之一）ΔmPQ 点估计 ≥ **.003**；
2. ΔmPQ 配对图像 bootstrap（组织内分层，1000 次）95% CI 下界 > 0；
3. Δstrict mPQ ≥ 0；
4. ΔDead PQ ≥ **−.002**；
5. 最优学习配置 > T1（若 T1 已解释全部收益，结论=简单聚合已够，不加深网络）；
6. 两个头种子 {0,1} 的 ΔmPQ 方向一致。

**止损条款：** 若只有 fold1 GT 区域诊断提高而 fold2 预测轮廓主端点不提高 → 暂停新分类结构，
先记录轮廓污染；若收益来自把无该类真值的图像报成该类或 strict 下降 → 停止该配置；若 T0–T3 全部
不过 → 记录失败位置（标签不可分 / 内部特征读不出 / 轮廓破坏信号 / 误报抵消），得到新的可检验
解释前不再追加配置。测试折 fold3 零读取；本轮结论只称 dev-fold 结论，三划分确认轮另行申请。

## 3. 配置（首轮 4 个，不扫描任何超参）

| 配置 | 定义 | 说明 |
|---|---|---|
| T0 | 现行规则恒等复评：逐像素 6 通道 argmax → 官方后处理实例多数票 | 直接评 `pred_fold2.npz`，须逐位复现 `eval_fold2` 的官方 mPQ（绑定检查） |
| T1 | 实例内概率均值：实例掩码内 6 通道 softmax 取像素均值，**丢弃背景通道 0，在 1–5 类 argmax**（背景规则就此冻结） | 不训练的聚合对照 |
| T2 | 冻结 `tp_feat`（64 维，`model.py` `return_features=True`）在实例掩码内均值池化 → 线性分类头 | 检验"特征够、读法不对" |
| T3 | T2 + 固定 24 px 上下文环：环 = 实例掩码圆形膨胀 24 px **减去全部实例像素**（自己与邻核均排除），环内特征均值池化 f_ring；特征 = **f_inst + f_ring（等维求和，容量与 T2 相同，不拼接）**；空环 → f_ring = 0 | 检验局部背景上下文；环宽、求和方式冻结，不扫 |

**线性头（T2/T3 共用）：** torch 线性层 64→5，softmax CE，AdamW lr 1e-3、weight decay 1e-4、
20 epoch、batch 4096，种子 {0,1}；类不平衡**不加权**（加权属于后续轮菜单）。确定性交叉核对：
sklearn `LogisticRegression`（lbfgs，C=1.0）复核方向一致，作稳健性记录，不作菜单项。

## 4. 数据划分与冻结输入（全部 train/val，fold3 不读）

- 冻结检查点：`runs/cellvit_uni/split1/final.pth`（seed19，x1，无 TTA）。运行时记录 SHA256。
- 验证预测：`runs/cellvit_uni/split1/pred_fold2.npz`（2523 图 / 59,593 实例），SHA256 绑定。
- 训练特征：fold1（2656 图 / 63,218 GT 实例）单次前向导出 `tp_feat` + tp softmax；GT 掩码池化，
  标签 = GT 类别。验证应用：fold2 单次前向，预测掩码池化（训练 GT 轮廓 vs 验证预测轮廓的域差
  单列报告，见 §2 止损）。
- 特征缓存：每实例 64 维 float32（fold1 ≈ 16 MB）+ 元数据（img、id、类、面积、触边），不存稠密图。
- 脚本级 fold guard：拒绝 fold3 与 split2/3 的输入路径（沿用 `fold_guard.py` 模式）。

## 5. 评测

- `fast_retype.RetypeEvaluator`：官方 mPQ + 逐类 PQ；**新增 strict 模式**（同一匹配表，GT 缺类而
  预测出现该类记 0 而非 NaN），TDD 先行。
- Δ 的配对图像 bootstrap：组织内分层重采样 1000 次，百分位 CI。
- 最终胜出配置：写出重分型 pred npz，用 canonical `pannuke_eval` 全量复评一次，与 fast 结果
  核对一致（容差 1e-6）后才写入 findings。

## 6. 预算与成本边界

- GPU：fold1+fold2 特征导出各一次前向，A100 batch 32 估计 <15 分钟（共 ~5.2k 图）；其余全 CPU
  （线性头训练分钟级）。
- 部署增量设计目标（非本轮门槛）：池化 + 线性头 ≤ 3 ms/img（x1 前向 15.5 ms/img 的 0.2×，即
  整体 ≤1.2×）；本轮实测并报告。

## 7. 风险

- 编码器训练时见过 fold1 → fold1 内训练准确率被高估；验证在 fold2 预测轮廓上，结论不受影响。
- T3 求和组合可能稀释实例信号（相对拼接的信息上限）——这是预注册的选择，为保容量可比；若
  T3 失败不能归因于"上下文无用"，只能归因于"求和式上下文读出无效"。
- 头种子只覆盖线性头随机性，不覆盖分割器种子（确认轮才扩）。
- 测试折多轮复用的历史限制不变；本轮不产生任何测试成绩。
