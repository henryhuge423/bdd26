# E1 候选盲审（抽样与两阶段盲评）设计 spec

起草 2026-10-10｜状态：**待用户批准，未启动。** 依据 [RESEARCH_NEXT_2026-10-09](../../RESEARCH_NEXT_2026-10-09.md) §4。
E1 的任务是**描述候选与标注的分歧**，不是证明 PanNuke 漏标，也不是替模型制造有利真值。

## 1. 抽样框与冻结对象（只读验证折，fold3 零读取）

- 冻结 pair：**split1_seed1**。理由：其 EF-P2 选择 `a200_p0.9_interior0` 非恒等（4,084 合格 /
  1,515 接受）；seed19 的 EF 选择为恒等，无"已接受候选"组。今日 readiness replay
  （`runs/analysis/e1_input_check_20261010_split1_seed1/`）已核对其候选记录与冻结
  `existence_audit_20261005_v2` 逐列一致，输入 SHA256 在案。
- 四个来源（各 50，共 200）：

| 源 | 总体 | n |
|---|---|---|
| S1 | x1 检出对象：`matched_seed_20261004/p0/split1_seed1/val/base/ms/pred.npz` 全部实例（EF 冻结管线所用的同一 base） | 50 |
| S2 | x2 独有且被 EF 接受的候选（`added=True`，n=1515） | 50 |
| S3 | x2 独有但被 EF 拒绝的候选（合格未接受，n=2569） | 50 |
| S4 | 随机背景窗口：fold2 图像均匀随机中心（无对象概念，只按组织分层） | 50 |

- 分层：S1–S3 按 **tissue × border**（候选记录自带 border 标记；S1 实例按同规则现算）；S4 按
  tissue。组内按比例分配；预注册合并规则：组配额 <3 时并入同 tissue 的另一 border 组。
- 抽样：无放回，种子 **20261010**；每个对象的入样概率（n_g/N_g）逐条记录，分析用
  Horvitz–Thompson 估计，按图像聚类（同图多对象不独立；无患者 ID 时只支持图像层结论）。

## 2. 材料包（生成脚本确定性，种子 + SHA 记录）

- 每窗口 **160×160 px**（对象质心为中心，clamp 入图），PNG。阶段一材料 = 图像 + 目标位置十字标；
  **不含**模型来源、置信度、面积、GT。四源混洗统一编号，评审不知道源分组。
- 阶段一表单（每窗口）：(a) 真实核 / 非核结构 / 当前视野不确定；(b) 若为核：完整 / 截断 / 多个
  碎片；(c) 可选最小轮廓。答案先封存。
- 阶段二（阶段一封存后）：图像 + 候选轮廓（S4 无轮廓，仅十字）+ GT 轮廓叠加；对准目标判断：
  与 GT 一致 / 边界偏差 / 与 GT 合并 / 过分割 / 可能漏标 / 非核。S4 加问：窗内是否存在 GT 未
  标注的疑似核。残余盲化风险（轮廓形状可提示来源）如实记录。
- 分歧仲裁单列：保留两份原始答案 + 仲裁结果 + 不确定项；报告两评审一致率与不确定比例，
  **不确定不并入假阳性**。

## 3. 评审与预试

- 两名具备病理形态判断能力的评审（**用户提供**；LLM/子代理只可组织材料，或做标注为"非专家
  预试"的材料可用性检查，不进正式结果）。若暂无评审：先交付抽样方案与材料包，不称 E1 完成。
- 分析脚本在收到任何评审答案**之前**冻结（预注册：按源分组的 HT 估计 + 一致率 + 与 GT 匹配
  标记的交叉表；200 窗口仅检验审计可行性，rare-class 亚组功效不足如实报告）。

## 4. 结果到路线的映射（预注册，来自提案 §4）

| 主要观察 | 动作 |
|---|---|
| 无匹配候选多为碎屑/背景 | 不开"正样本未标注"路线；仅在简单特征可分时考虑质量筛选 |
| 真实核多但属形状/裁剪/实例单位不一致 | 优先边界与可见实例诊断，不先提类型置信度门槛 |
| 存在可重复确认的疑似漏标 | 单列独立专家评测，保留官方 GT 成绩；未扩展验证不宣称数据集系统漏标 |
| 评审对"是否核"都难一致 | 先完善标签规范，暂停监督学习 |
| 有可靠有效候选且可预测 | 才进入训练折内交叉拟合的候选质量学习 |

## 5. 护栏

- 只读 fold2（split1 验证折）；抽样与材料脚本 fold-guarded，拒绝 fold3 / 其它 split。
- 不因审计结果修改任何已冻结 EF-P2 结果或历史成绩。
- E1 不能回答"网络特征是否有信号"（那是 T 实验），也不自动提供 Inf/Conn 标签质量结论；
  若 T 提示 Inf/Conn 标签模糊，另建分类审计样本（覆盖混淆与非混淆对象）。

## 7. 修订（2026-10-10 批准）：无专家条件下的 E1 替代执行

背景：暂无具备病理形态判断能力的评审。本修订把 E1 的证据来源从"人眼生物学裁决"替换为
两类**不作生物学断言**的证据，人类评审义务保留（未来可得时仍可对同一材料包执行原协议）。

### 7.1 E1-C：跨检测器共识分析（证据主体，零判断）

- **原理**：jury 全部是只被 GT 监督过的检测器。对 GT 未标注对象的一致检出是"标签可疑"
  的反向证据（检测器只能从相似已标注核泛化，偏置方向偏向 GT）；仅来源 run 检出、其余
  全无响应则与碎屑/过分割相容。所有输出表述为**检测器共识证据**，不称生物学结论。
- **Jury（预注册固定，13 席；来源 run split1_seed1-x2 剔除）**：
  split1_seed{19,1,2} 与 split3_seed{19,1,2} 各 {x1, x2} 的验证折 identity（原始解码）
  预测 = 12 席中的 11 席（split1_seed1-x2 为来源，排除），加 HoVer-Net split1 与
  split3 的 fold2 推理（唯一新增 GPU，2 次）。全部成员的训练折 ∈ {1,3}，fold2 从未
  参与其训练；split1/split3 的 val 折恰为 fold2。
- **支持度**：检测器 j 支持候选 c ⟺ j 在 c 所在图中存在预测实例与 c 的 IoU ≥ 0.3。
  0.2/0.5 作描述性敏感性，不进判定。
- **输出**：S2/S3 支持度分布；支持度 × GT-matched 交叉表；支持度 × 面积/触边；
  S4 背景窗内 jury 实例密度（GT 阴性空间 FP 率的 proxy）。
- **预注册解读键**：未匹配候选 支持 ≥ 3 且含跨训练折或跨架构成员 → "多检测器共识、
  标签可疑"；支持 ≤ 1（仅来源族）→ "孤立检出、碎屑相容"。中间带如实报告比例。
- **护栏**：fold-guarded；不读 fold3；来源 run 不进 jury；判定阈值运行前冻结。

### 7.2 E1-M：非专家模型盲评（两轮独立，标注性质）

- 现有 200 窗口材料包 stage-1（图 + 十字，无来源/置信度/GT）上，两个**相互独立**的
  视觉模型通道各评一轮，填冻结的 stage1 表单；用已冻结的 e1_analyze.py 汇总。
- 报告：轮间一致率、各源 HT 率、与 matched 交叉表；全部标注
  **"非专家、误差与分割器相关"**。
- **排除**：stage-2 生物学裁决；§4 中"数据集漏标"路线的触发；任何"E1 已完成"表述。

### 7.3 路线映射修订

E1-C/E1-M 只驱动工程分支（如"存在支持度可预测的候选子群 → 原型化候选质量学习"）；
漏标类主张永久留给人类评审。本修订不回溯修改已生成的材料包与分析脚本冻结状态。
