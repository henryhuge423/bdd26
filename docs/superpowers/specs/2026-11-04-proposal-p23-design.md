After EVERY successful AdamW update, including the six-image tail, apply shadow = .999*shadow + .001*online, in place under no_grad. No EMA feedback into loss, gradients, optimizer, RNG, data order or online weights. BF16 autocast has no GradScaler, hence no silent skipped update; any nonfinite gradient/loss aborts. The successful-update counter must equal134*130=17420 at completion (nine steps in the134-image smoke).

Inventory buffers: this model is expected to have none. Fail closed if a buffer is present rather than inventing a running-statistics policy. E combines averaged trainable parameters with C's unchanged frozen parameters. C is saved/evaluated first; load EMA in the same model only after C outputs are finished. Check immutable C checkpoint and cloned shadow identities. Last training checkpoint contains online adapted state, optimizer, configuration, EMA shadow and update count. No resume is implemented or allowed; existing output directories are refused. A failed run is preserved and cannot silently resume or substitute a shortened epoch count. A future resume requires a separately verified protocol, including all RNG state. Test shadow state round-trip and malformed/partial/wrong-step rejection; do not claim training resume support.
