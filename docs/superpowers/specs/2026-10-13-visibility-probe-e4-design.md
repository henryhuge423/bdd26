# 视野裁剪可见性机制探针（E4）设计 spec

起草 2026-10-13｜状态：**待用户批准，未启动。** 依据 [RESEARCH_NEXT_2026-10-06](../../RESEARCH_NEXT_2026-10-06.md)
§4 路线A + §5 E4（受控 FOV 裁剪 × 相位平移 × 插值机制探针）。本轮是路线A的**准入探针**：不训练，
仅在冻结检查点上做受控推理与 GT 身份对应分析；可见性监督训练轮须凭本轮预注册门**另行立项**。

## 1. 背景与动机

- 57% 的 Dead FN 是边界碎片（基准产物分析）；存在性审计 v2：贴边候选 GT 匹配率 52.86% vs 内部
  26.15%——边缘对象行为与内部系统性不同。
- E2a：内部 Dead 匹配率 61.3%→71.0% 的尺度提升不被 HV 门槛解释——存在未解释的尺度效应。
- 训练管线事实（`src/nucseg/cellvit/data.py`）：`RandomSizedCrop` 仅 p=0.1；监督不区分截断/
  完整对象；HV 目标对 <30 工作像素的对象清零——**截断碎片可能静默失去 HV 监督**。
- 路线A假设：网络被要求把"完整小核 / 大核的可见残片 / 同一对象多个碎片"输出成同一形式而无
  可见性表述，是否造成可定位失败？本探针先在冻结模型上检验失败是否存在、可否构造复现、
  机制是否指向碎片面积/HV 监督。

## 2. 假设、端点与门（进入训练轮的判定，三项全过才立项训练）

miss 定义：GT 核与全部预测实例的最大 IoU < .1（any 类；与原始诊断口径一致）。

- **H1 自然边框**：贴边 GT 核（触碰原图外圈像素）miss 率高于同类同面积段内部核，Dead 差距最大。
  **门1**：Dead 贴边−内部 miss 差 ≥ **+.05**，图像聚类 bootstrap（组织内分层，1000 次）95% CI
  下界 > 0。
- **H2 构造 FOV 因果**：嵌套裁剪把原完整核变为截断后，其检出相对 (a) 裁剪前自身 (b) 同窗内
  保持完整的核下降，超出插值噪声。
  DiD = [P(miss|新截断, Ck) − P(miss|同核, C0)] − [P(miss|保持完整, Ck) − P(miss|同核, C0)]。
  **门2**：C2 的 DiD 点估计 ≥ **+.03** 且 CI 下界 > 0，且 |C-int 的 DiD| < C2 的 DiD。
- **H3 碎片面积机制**：新截断核的 miss 随可见碎片面积（裁剪坐标原生 px）上升而下降。
  **门3**：<30 px 档 miss − ≥100 px 档 miss ≥ **+.05**，CI 下界 > 0。

三项全过 ⇒ 允许起草可见性监督训练轮 spec（另立项，对照至少含 crop-augmentation 加强版与原
基线）；任一不过 ⇒ 路线A按止损关闭，记录失败位置。门数字运行前冻结，运行后不放宽。

**次端点（描述性，无门）**：visible-mask IoU、split/merge 率（复用 `metrics/errors.py` 既有
定义）、matched 类型正确率、预测 HV 误差（碎片内 |pred−ideal|，ideal = 截断 GT 掩码的
`hv_targets(min_size=0)`，仅诊断用）、逐组织分解、crop-frame 图像级 mPQ/bPQ。

## 3. 条件（冻结，5 个）

| cond | 构造 | 隔离 |
|---|---|---|
| C0 | 原图 256；直接复用 `pred_fold2.npz`（绑定：恒等复评 == `eval_fold2` 官方 mPQ 逐位） | 基线 |
| C1 | replicate-pad 平移 (dy,dx)=(12,12) | token 相位 |
| C-int | 全图 256→192→256（bilinear，同 `upsample_patch` 插值） | 插值噪声地板 |
| C2 | 抖动 192 裁窗 → resize 256（zoom 1.333×） | FOV 移除+放大（DiD 分离） |
| C3 | 抖动 160 裁窗 → resize 256（zoom 1.6×） | 剂量响应 |

- 裁窗抖动：每图每尺寸一个窗口，偏移由 rng(seed=20261013) 在合法范围均匀采样
  （192: {0..64}²；160: {0..96}²），逐窗记录偏移与新截断对象清单。
- 预测在**裁剪坐标系**评估：模型输出映回裁窗坐标，与裁剪后可见 GT（裁剪坐标系内为实例）
  匹配——与 PanNuke"可见片段即实例"的标注约定一致，不构造视野外假 GT。
- 解码常量不动（min_size 10 等，工作尺度 256 原生）；C2/C3 的 zoom 使这些常数相对组织缩小，
  如实披露，不做 du 式补偿（那是另一变量，DiD 内部对照共享同一解码）。

## 4. 对象分组（构造身份对应）

- **原完整**：GT 实例不触碰原图 256 外圈像素。仅原完整核进入 H2/H3。
- 裁剪后分组：**新截断**（掩码交裁窗边界）/ **保持完整** / 完全落窗外（剔除）；
  碎片面积档（裁剪坐标原生 px）：<30、30–100、≥100。
- H1 用全部 GT 核（贴边 = 触碰外圈），按类 × 面积段（<100、100–400、≥400 原生 px）分层。

## 5. 数据与冻结输入（split1 train/val 纪律，fold3 零读取）

- 检查点：`runs/cellvit_uni/split1/final.pth`（seed19，x1，无 TTA；运行时记录 SHA256）；
  新推理同样无 TTA，batch/workers 沿既有 predict 设置。
- 图像/GT：`data/pannuke` fold2（split1 验证折，2523 图）；fold2 同时是 T 轮验证折——本轮
  只读分析、无训练、无选择，披露即可。
- C0 绑定：`pred_fold2.npz` SHA256 记录。
- fold guard：拒绝 fold3 / split2 / split3 的任何输入路径。

## 6. 统计

- 逐核配对（同核跨条件）差率；图像聚类 bootstrap 1000 次（组织内分层）；逐组织分解报告；
  种子/训练随机性不在本轮（冻结检查点单模型，结论表述为该检查点上的机制证据）。

## 7. 实现

- `scripts/probe_visibility.py`：条件构造、批量推理（复用 predict 前向与解码）、GT 身份对应
  表、全部端点 → `runs/analysis/visibility_probe_20261013/`（JSON + 表 + commands.md）。
- 结果文档 `docs/E4_VISIBILITY_PROBE_2026-10-13.md` + findings 条目；门判定三值（H1/H2/H3）
  从 JSON 工件直接复算。
- 单元测试：条件构造的确定性（同 seed 逐位复现）、坐标映射正确性（合成数据：已知圆盘经
  C2 后的可见面积/触边标记）、C0 绑定检查。

## 8. 风险与边界

- 截断必然发生在窗边——空间位置与截断不可分离；配对设计 + C-int 校准插值/相位，不校准位置
  本身，披露为限制。
- C2/C3 的 zoom 与 FOV 移除共变——DiD（同窗保持完整核作对照）分离放大效应；C3 为剂量点。
- C1 的 replicate-pad 造人工重复纹理；主结论不依赖 C1。
- 过门 ≠ 训练轮会成功；训练轮 spec 另行预注册，含成本与停止规则。
