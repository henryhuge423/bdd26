# P26 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Test fixed pretrained-weight anchoring with original C as exact control.
**Architecture:** Isolated P26 runner extends the original P25 C model/data path; anchor only trainable encoder tensors on R and add its penalty once per effective batch. Separate real-GPU witness checks exact original parity and the actual regularizer effect.
**Tech Stack:** Python 3.10, pinned PyTorch 2.5.1+cu124, NumPy 1.23.5, pytest.
**Spec:** ../specs/2026-11-10-proposal-p26-design.md.

## Global Constraints

C/R x seeds19/1, fold1 fit2134/audit522, physical4/effective16, 130 epochs and last; original frozen admission, exact .01 sum penalty, no threshold/menu/restart. 48 GPUh formal and 30 minute validation cap. Do not touch common model/metrics or existing outputs.

## Review Focus

- Zero initial drift must yield zero penalty without introducing RNG calls into C.
- An incomplete effective batch receives precisely one penalty, independent of its image count.
- Head/frozen parameters and anchor copies never enter the anchor or optimizer incorrectly.
- Different arm/seed/lambda/source configuration and output overwrite must fail closed.
- Both checkpoint variants reload inference exactly without serializing anchors.
