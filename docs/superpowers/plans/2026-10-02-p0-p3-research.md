## Review Focus

- Sparse/noncontiguous instance IDs and signed/unsigned dtype must not change class lookup or geometry.
- Background and outer-image edges must contribute exactly to each real instance perimeter.
- Merged outputs must not carry stale per-instance probability tables.
- Every subset row must map to its original fold image index; inference scale must be explicit and consistent with decode scale.
- Non-improvement, empty classes, duplicate seeds, false positives in class-absent images and overlapping test folds must remain visible in summaries.

## Decisions fixed before new experiments

- P0 original small menu: merge fraction `{none,0,0.25,0.5,0.75}` × border-area `{0,20,40,80}` in native 256-pixel units. Include identity; select maximum validation official mPQ subject to bPQ >= identity bPQ - .002, with deterministic conservative tie-breaks. This reproduces the existing validation budget, not a new test-derived sweep.
- Compare base/base+corrected M/S and du2/du2+corrected M/S for seed19 on all three splits. Additional existing seeds are evaluated only after the primary chain if time/resources allow; missing seeds are not trained.
- P1 diagnostics use both validation (decision source) and test (descriptive only), clearly separated. Oracle selection is an optimistic diagnostic, never a deployable score or performance claim.
- P2 gate uses validation only. Require a positive type-correct complementary candidate pool and test a small fixed candidate rule menu; select only if validation mPQ and bPQ each >= base-.002, strict Dead PQ >= base, and interior Dead IoU>.5 matched count increases. A failure is a completed negative experiment, not permission to expand the menu on test.
- P2 masks preserve every base instance and add only wholly non-overlapping x2 candidates. Native area thresholds `{100,200}`, class confidence thresholds `{0.5,0.7,0.9}`, and no-border vs any-border form the initial fixed menu, plus identity and unfiltered non-overlap controls. Use original du2 probability tables with validated image/id mapping, never old lever sidecars. Only transfer types on stable one-to-one overlaps for the typing diagnostic.
- P3: seed19 split1 first, validation fold2 only, deterministic 128-image tissue-stratified subset (all available tissues represented; selection uses tissue/index, not model outcomes or Dead labels). Four train/infer scales `(1,1),(1,2),(2,1),(2,2)`; decode_u=inference_scale; no TTA, batch2. Repeat other splits only if this bounded run succeeds and adds value. Report as a one-split mechanism probe, not a 3-split benchmark.
