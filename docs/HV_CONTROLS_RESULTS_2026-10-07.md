# HV 目标门槛对照：结果与机制分析

**2026-10-07 · E2a 收尾 · split1 / validation fold2 / seeds 19、1**

> **结论：HV 小实例监督门槛确实是需要控制的变量，但不是 x2 效应的完整解释。**
> x1 从 hv30 降到 hv8 没有稳定改善；x2 从 hv120 降到 hv30 的官方 Dead PQ 在两个种子上均提高，
> 但图像 bootstrap 区间仍跨零。固定原生面积支持后，x2 对内部 Dead 的匹配优势与 bPQ 代价均保留。
> **这是单划分、双种子的验证集机制实验，不是新的三划分测试成绩，不替换 EF-P2 的正式结果。**

## 2. 冻结设计与统计口径

| 臂 | 工作尺度 | HV 门槛（工作 px²） | 原生整数面积支持 |
|---|---:|---:|---:|
| x1_hv30 | 1 | 30 | ≥30 |
| x1_hv8 | 1 | 8 | ≥8 |
| x2_hv30 | 2 | 30 | ≥8 |
| x2_hv120 | 2 | 120 | ≥30 |

原生支持对应最近邻精确 x2 放大后的面积条件。门槛只控制实例是否进入非零 HV 目标生成；
**被排除的实例仍保留 NP/TP 标签，HV 目标为零，并非忽略损失**。匹配支持不等于两个尺度的
像素目标、梯度、图像插值和解码行为完全相同，也不单独识别 token 尺度效应。

共同配方：split1、seeds {19,1}、130 epochs、batch16、encoder 前25轮冻结、lr 3e−4、
ExponentialLR γ=.85、sampler γ=.85、原增强，无额外重加权/合成/TTA/M/S/EF。
数据为 fold2 的 **2,523 张图、19 种组织、59,872 个 GT 核**；其中 Dead **884 个、分布在70张图**，
内部741、贴边143。两种子共享这些对象，不构成两批独立样本。

- 主表为两种子算术均值；逐种子成绩完整列出，不选最好种子。
- 官方 mPQ/bPQ：图像 → 组织内平均 → 组织平均；Dead PQ：含 Dead GT 图像上的类别 PQ 平均。
- 95% CI：2000 次组织分层、成对图像 bootstrap，RNG seed 20261006；每次重采样在两个训练种子
  和四项对比间共用。它只反映**给定这两个训练模型的图像抽样不确定性**，不是训练种子或患者级显著性。
- strict mPQ、strict Dead PQ、mPQ+ 从 evaluator summary 读取，只有点估计、没有本轮 CI。
  `mPQ+` 仍是类别感知指标，不能解释为纯检测成绩。

### 可支持的解释

1. **x1 降门槛不是有效替代 x2 的证据。** Dead 方向随种子翻转，平均只 +.001441，
   bPQ 两种子均降低。不能因 strict Dead 均值提高就忽略官方指标的不稳定和整体代价。
2. **x2 下 HV 门槛有候选信号。** hv30 相对 hv120 的官方 Dead 在两个种子均提高，均值 +.009817；
   但 CI 跨零，strict Dead 在 seed1 下降，尚不足以称稳健或无代价提升。
3. **面积支持混杂不能解释全部尺度代价。** 两组匹配支持的 x2−x1 比较都保留 bPQ 下降，
   CI 均低于零，且两个种子同向。官方 Dead 均值升、strict Dead 均值降；两种指标须并报。
4. **不能宣称纯分辨率因果机制已经定位。** 固定面积门槛排除了一个特定混杂，但尺度同时改变采样、
   特征表达、目标离散化和尺度化解码；还未隔离训练日程及其它因素。

## 5. 对象级诊断：尺度作用仍在，门槛作用有限

`matched` 是 evaluator 的类别无关一对一 IoU>.5 匹配；`missed_bg` 是最大 IoU<.1，
并非必然零重叠。下表为两种子的率均值；每格分母是同一固定 GT 子集。

### 5.1 内部与贴边 Dead

| 臂 | 内部 matched /741 | 内部 missed_bg /741 | 贴边 matched /143 | 贴边 missed_bg /143 |
|---|---:|---:|---:|---:|
| x1_hv30 | 61.27% | 26.86% | 40.21% | 53.50% |
| x1_hv8 | 62.42% | 25.78% | 39.16% | 54.20% |
| x2_hv30 | 71.05% | 14.24% | 48.95% | 37.76% |
| x2_hv120 | 70.99% | 14.30% | 48.25% | 39.51% |

内部 matched 数（seed19 / seed1）依次为 **475/433、476/449、530/523、530/522**；
内部 missed_bg 数依次为 **175/223、171/211、103/108、105/107**。
贴边 matched 数依次为 **56/59、56/56、67/73、68/70**。

固定高支持时，内部 Dead 匹配率 61.27%→70.99%；固定低支持时为62.42%→71.05%。
相反，在 x2 内降低门槛只让平均内部 matched 数从526增至526.5（两种子共增加1个），
不足以把 +.009817 的官方 Dead PQ 增益简单解释成“找回大量内部 Dead”。
内部**匹配且分型正确**的数在 x2_hv120 为380/367，在 x2_hv30 为383/351，也不是逐种子增加。
PQ 还受形状、误报、组织/图像权重与分型影响；本轮未做完整的增益来源分解。

这些面积组混合各类别与边界状态，不能当成纯内部小 Dead 结论，亦不产生新的过滤菜单。

## 6. 研究决策与 DSB 交接

- **保持默认 hv_min_size=30**；没有证据支持把 x1 全局改成 hv8。
- x2_hv30 仍可作为后续机制实验的冻结参照，但不宣布本轮三划分收益，不改变既有 EF-P2 成绩。
- 按另行冻结的 DSB gate A 算术：
  - x1 降门槛的 ΔDead = +.00144097；
  - x2_hv30 相对 x1_hv30 的 ΔDead = +.01502907；
  - 比值 **9.59%**，低于50%换基座线，也不满足90%且无税的降级线；
  - 因而 **DSB/C0/C1 基座应保留 x1_hv30**。这是预声明规则的点估计代入，
    不是“门槛只解释9.59%的生物机制”的中介因果估计，也不是所有 DSB 闸门通过。
- DSB 当前是独立的进行中开发：已有模型/目标/损失/TTA 提交，还有未提交的 CLI、合并和 dev-eval 工作。
  **本次只发布 HV 分支，不合入未完成 DSB，也不启动 DSB GPU 任务。**
  梯度冲突、L0 决策解耦上界、oracle 上界及相应验证仍需按 DSB 计划完成，之后才谈训练。
- 若继续研究，应先完成这些机制闸门和完整成本对照；不因双种子 Dead 点估计为正就扩大确认轮算力。

## 7. 限制、成本与复现

1. 单划分、两个训练种子、70张 Dead 阳性验证图；不能外推三划分均值、独立患者泛化或训练种子显著性。
2. 本轮验证集并非新采集的独立队列。所有 Dead 对比 CI 均跨零；不能把“不显著”说成等效或零作用。
3. 官方/strict 方向不一致必须保留。对象匹配率不是 PQ、typed-correct/GT 也不是匹配后条件分类准确率。
4. 全部训练日志的 epoch 时间合计 **41.76 小时**；共享设备、负载变化且部分种子对跨物理卡运行，
   这不是受控 GPU 吞吐、专用 GPU 计算量或端到端部署成本。尚无可报告的推理 p50/p95、峰值内存对照。
5. 新的独立代理审查因服务不可用未完成；本轮采用直接源码/证据复核与完整 CPU 测试，
   不将代理调用失败写成独立审查通过。此前实现及推理 provenance 审查记录保留于原计划。
