# 接下来怎样找到更多核，同时减少额外预测点

最新实验发现，同一个核可能在原图像位置下没有被找到，换一个与模型图块网格的对齐位置后就出现了预测。还有一些核的预测位置已经很接近标注中心，但分数低于原先的 0.5 阈值。例如结肠组织图像 1482 中一个死亡核的分数为 0.486：降低阈值后，它重新成为有效匹配。

这解释了为什么上一轮降低阈值会大幅增加检出数量。两个平移训练模型找到的内部死亡核从 44/44 个增加到 101/99 个，总数为 145。然而，新增点中也出现了很多额外预测，精度降至约 66%。下一步的核心是筛选这些候选点。

P38 先把多个对齐位置的近邻预测点分成组，再问一个组是否值得保留。支持它的对齐位置越多、原始分数越高、位置越集中，可能越可信；这些关系需要通过训练图像学习和验证。一个组即使很稳定，也可能整体偏离标注中心，所以位置一致性不能单独决定正确性。

实验设两个直接对照：一个只看支持数，另一个结合分数、支持和位置离散程度学习质量评分。它们使用相同候选点和相同输出位置。240 张训练图像分为两组，一组学习评分，另一组选择保留规则。全部规则保存后，再评估 522 张开发图像。两个种子、原匹配标准与双种子判定保持固定。

此前的 P34 位置读出模块会新找到一些核，也丢失接近同样数量的原有匹配；P35 直接平均分数图会压低错开的峰。P36 和 D37 则提供了完整保存点和逐对象证据。因此，P38 先复用这些记录检验筛选方法，通过 Expanse CPU 作业执行，不需要重新训练检测器。

本轮已完成，保存了八张固定图像，显示标注中心、上一轮位置汇总、仅按支持数筛选和新质量评分的预测。绿色加号表示匹配点，红色叉号表示额外点，黄色圈表示漏检。完整坐标记录可以逐个解释新增与丢失核，并分析小核、拥挤区域和不同组织中的变化。所有固定图像都保存，不根据结果好坏挑图。

下一步将优先研究保留可信原预测、评估补充候选的边际收益，再判断怎样通过训练和较少的前向计算实现稳定收益。[详细中文分析](REVIEW_ZH.md)和[固定实验方案](FROZEN_DESIGN.md)说明了前期证据与具体统计标准。

本轮实际结果表明，平移训练模型的质量评分减少了两个种子的 676、377 个额外点，精度提高到 71.99%、70.17%，仍低于原定 75% 条件。相对同样校准的对照，死亡核召回提高 8.28、9.66 个百分点，成对区间均为正。全层模型则增加了不少额外点，简单支持数筛选更稳健。

在[结肠图像 1482](figures/P15_J_s19_1482.png)里，一个核得到十一个位置支持，预测点只偏离标注中心 1.69 像素，却因为质量评分不足被删除。这说明下一步应保留可信原预测，再评估补充点能否找到新的核，同时减少重复点与背景点。完整八图和逐对象分析见详细中文报告。
