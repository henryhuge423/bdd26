# CellViT dead 增强与 PM-Net：研究判断及新增审计

日期：2026-10-18，America/New_York。

## 判断

应停止继续扩展已经失败的 CellViT 增强配方，将研究重点转向“可泛化的实例检测与分割”。但不建议立即按原提案搭建并大规模训练完整 PM-Net。原 PM-Net 的门控、查询、点生成和高分辨率模块已有相当多直接相关的负证据；给它换一个模型名称并组合这些模块，不会自动获得新的科学依据。

“目前没有通过门槛、值得扩量的 CellViT dead 增强方案”是成立的实践判断。“基于 CellViT 再也不可能改善 Dead”则超出了证据。基线仍然是最重要的比较工具，不能因改进失败而弃用。

这些近期结果来自开发折或训练诊断，不是新测试成绩。P1-R1 的点召回、NP-component proxy 与 E19 的掩码 IoU>.5 匹配不是同一种指标，不相减解释流水线损失。多次实验共享数据与实现，不能把失败次数当作独立统计证据。

E5 的 strict Dead PQ 同样提高，因此不能把其全部收益解释成 official 缺类规则的漏洞；但匹配集合发生变化、且没有容量匹配对照，仍不能因果归功于门控。E19 的 strict Dead 上升与 official Dead 下降也提示：指标定义及组织平均会改变结论，不能事后选择有利端点。

“共同未匹配”指四模型都未达到 max-IoU>.5，包含形状不达标的对象，不等同于完全无重叠。此前审计的严重漏检定义是四模型都 max-IoU<.1，共149个；本次没有重定义这一端点。

新增证据：

1. **小尺寸相关性很强，但不构成单一尺寸原因。** 持续未匹配对象面积中位数64，四模型始终匹配对象中位数122；≥158组仍有35个持续失败对象。
2. **不是简单的粗粒度训练支持缺失。** 面积×对比度16格全部在训练折有支持，每格29–73对象、来自16–27图；最小且低对比度格训练39对象/19图，开发34对象，其中29个持续未匹配。该格有训练样本，不意味着外观、患者或组织联合分布已经覆盖。
3. **训练与开发的全体边际分布接近。** 面积中位数103 vs100，对比度中位数71.64 vs74.91。这只能排除“这些简单边际描述明显缺失”的解释，不能排除条件域移位或隐含患者相关性。
4. **不能将邻近实例视为统一解释。** 8像素内有其他标注对象的比例，持续失败组148/233=63.5%，始终匹配组247/395=62.5%。这不是接触率，也没有控制尺寸/组织，不能作因果结论。
5. 这两个折的内部Dead实例均为8连通，但不能因此断言标签正确、没有碎裂或生物学歧义。专家评审缺失仍是限制。

此审计仅用于构造下一轮问题，不据此调整开发门、筛选新模型或将开发对象作为训练难例。

## 对 PM-Net 的具体含义

原提案的 P1→P2 前置条件没有满足。P1-R1 只否定冻结特征、小卷积点头、无增强这一组合；其结果既不能否定可训练检测器，也不支持直接增加容量、堆叠模块或扩大种子。

若继续 PM-Net，应把它重新立项为独立的新假设，先解决实际预测点集合的召回、精度和泛化，再接掩码头。优先问题是：“在不使用真值位置的条件下，可训练的检测表征与标准训练增强，能否改善小对象的跨图像泛化？”这是候选研究方向，不是已经验证的机制。

下一轮应先形成一个独立的 train-only 开发方案：在fold1按图像划分新的拟合/审计队列，冻结种子、停止规则、解码与候选数/精度要求；用可训练表征×训练增强的受控对照区分两者贡献，保留固定NP候选参考；同时检查小对象训练内是否学会以及留出图像能否迁移。不得用小队列过门替代完整fold1→fold2开发验证，更不得直接进入三split确认。

只有实际推理候选集合形成正向证据后，才值得开展点条件掩码和联合训练的匹配对照。最初版本不叠加门控、层次分类、可见性、稀有类重加权等多个变量。原有质量、成本与最后检查点规则保留；新的独立规格必须在看新结果前明确完整训练预算，不能靠看到负结果后追加步骤。

若希望检验高分辨率路线，真正的多阶段编码器注入与 E19 的单skip残差是不同问题。[CellVTA 原文](https://arxiv.org/abs/2504.00784)描述了通过交叉注意力向ViT注入CNN空间信息，不能将E19写成其完整复现。[PromptNucSeg 原文](https://arxiv.org/abs/2311.15939)使用学习式点提示器与微调SAM及邻近负提示，也不能用P1-R1的小冻结特征点头结果替代对其方案的检验。这些文献支持保留研究空间，不保证本项目Dead增益。
