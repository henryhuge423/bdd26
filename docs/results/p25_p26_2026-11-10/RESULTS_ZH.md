# P25：总体找点更好，死亡核漏检仍多

P25 四次训练全部完成。新方案 D 在两个随机种子下都找到了更多核，并减少了额外点；死亡核找回率为52.4%和51.7%，低于事先确定的60%最低要求。完整通过条件在两个种子下都未满足，这一组设置不再继续扩展。

项目最终要画出每个细胞核的轮廓并分类；这里先比较能否找到核的中心。召回率是标注核中被找到的比例，精度是预测点中成功匹配标注的比例。训练图用于学习，审计图用于比较方案；两个随机种子分别重复训练，检查结果是否稳定。

对照 C 只训练图像编码器的最后12层；D 训练全部24层，并让前层学习率较低、后层较高。其余数据、训练次序、增强、损失、130轮和最终模型读取规则相同。这次比较检验的是层数与分层学习率的组合。

新方案分别多找到了741和512个核，同时少了510和544个额外点。这个改善有实际意义。但目标亚组仍有较大缺口：32个小死亡核中，有22和20个没有找到。

死亡核净增为7和10个，即4.83和6.90个百分点。原方法重采样区间为[−1.04,+16.48]和[0,+19.40]个百分点，下界均未严格大于零；两种子的绝对找回率和精度也低于60%/75%。原判定函数和独立复算给出同一结果。

改善主要来自肺组织图像，两个种子分别净增9和8个死亡核；结肠图像分别净减7和6个。含49个死亡核的结肠图1482尤其突出，命中从15降到9、从14降到10。肺和结肠五张图合计包含116/145个死亡核，因此这些变化会明显影响整体结果。完整11张图的明细在阶段报告中保留。

逐次去掉一张含死亡核的图，增益范围分别为1.6–13.54和3.2–14.58个百分点。这用于看单张图的影响，原本包含全部11张图的计算和通过条件保持不变。

预先固定的八张审计样例含53个死亡核。逐对象比较显示，种子19保留26个、找回11个、丢失6个、两边都漏10个；种子1对应30、8、4、11。图中的新增和丢失可以同时发生，净增数只表示两者之差。

在参与训练的图上，D 两个种子都找到了649/656个内部死亡核，约98.9%；审计图上仅约52%。训练图和新图的差距仍是下一步要解决的问题。D 的纯训练时间约为 C 的1.41/1.42倍，训练峰值显存为6.745 GiB，对照4.047 GiB；四个作业合计19.9881 GPU小时。

下一轮 P26 在两组都保留原C模型和学习率，只给新方案增加一项约束，让可训练编码器参数保持在预训练值附近。约束系数固定为0.01，检测头不受这一项约束，原权重衰减保留。两种子各比较一次，均训练130轮并使用最后保存的模型；原通过条件不变。验收和提交状态另记在回执中。
