### 1.2 研究贡献的合理定位

- **最坚实：可审计的评测与失败机制证据。** 同一评测器、原始类别通道、最终 checkpoint、修复后重算及负结果记录，比不可比较的排行榜小幅差异更有价值。
- **有价值但有限：跨尺度候选的互补性及错误代价分离。** 类型置信度能够排序条件分型质量，但不能代替对象匹配质量；EF 表明一个简单面积控制可显著减少平均误报代价。
- **还没有：独立临床/患者级验证、普遍的无损提升、完整部署优势或新架构贡献。** 简单面积门控本身也不足以构成强方法论文。

课程项目层面成果完整；若希望形成更强的研究论文，应把“多轮调参终于涨一点”改写为一个新的、可以被否证的机制问题，并增加独立数据证据。

## 2. 数据特点决定下一步不能照搬通用方法

### 2.1 Dead 不是单一的“凋亡小黑点”

PanNuke 原文 Table II 将 **Apoptotic 与 Necrotic 都归入 Dead** [D1]。这是必须修正的概念：

- 生物学上已死亡的细胞；
- H&E 上可见的凋亡/坏死形态；
- 被标成某个 PanNuke Dead 实例的区域；

三者不是同义词。论文没有给出足够明确的碎片归并、边缘截断实例计数或分子确认规则。死亡对象还可能失去原细胞谱系信息；不能指望一个文本原型覆盖所有形态。

既有历史分析记录显示：fold3/fold1 含 Dead 的图像约97/65张，top10 图像占 Dead GT 约43%/51%；含 Dead 的 Uterus 图像约34/2张。Uterus 难例还包括较大、苍白、腔内脱落对象。**这些分布数字本轮只核对了历史记录，未重新扫描原始 GT**，详见 `docs/findings.md` 对应 Dead/边界审计。

因此下一轮应至少分开分析：内部完整小核、内部大/苍白 Dead、视野边缘截断对象、碎裂群。组织只用于预声明分层和部署可获得的条件，不能把测试组织标签偷偷当推理额外真值。

### 2.2 “小”混合了真实小对象和截断对象

既有分析中，小于60px的 GT 大量触边，边缘对象也占漏检的重要部分。对全部小核统一重加权，可能主要优化边缘残片，而不是内部 Dead。这使此前小核加权的负结果无法否定针对完整内部 Dead 的数据干预。

但也不能反向推导“边缘都应该删”：本轮重聚合冻结验证候选，边缘匹配率 **5273/9975 = 52.86%**，内部为 **1931/7384 = 26.15%**；正确新增 Dead 却主要在内部（614 vs 85）。面积、组织、类别构成存在混杂，这些是描述性分组，不是新门控规则的依据。

### 2.3 官方 FP 不等于生物学上不存在

冻结验证添加共17,359个，其中7,204个按现有 IoU 匹配（41.50%）。小于30px的添加仅454/2294匹配（19.79%），30–60px为44.40%。未匹配可能包括：

1. 真正背景/debris；
2. 真实核但形状不达 IoU>.5；
3. 原 GT 未标的真实对象；
4. 一核多碎片或多碎片一核的实例单位分歧。

目前没有人工证据证明其中任一种占主导。故以 `IoU>.5` 为标签训练的头应叫 **matchability / 可匹配性头**，而不是已经学会“真实存在性”。只有独立专家审计才能部分分离生物对象和标签过程。

Foucart 等关于小核边界敏感性的研究支持这个区分 [D2]。保持原官方成绩，同时补充定位、边界、分型诊断；不能因为某个指标不利就替换它。

### 2.4 x2 改变的是工作尺度，不是采集信息

项目标称原始 MPP=.25，ViT patch=16。256→512插值使每个token覆盖的原图跨度从16px变为8px，token数256→1024；若采用朴素全局注意力，其两两关系数量约增加16倍，**这不等于整网时间或显存必然16倍**。

它没有增加光学信息或原图外上下文。当前模型已有全分辨率 `skip0` CNN（`src/nucseg/cellvit/model.py:76`），所以“原来完全没有细节通道”也不成立。

现有30px过滤在原生标称尺度下对应1.875 µm²，等面积圆直径约1.55 µm。它是基准上的经验过滤，不是细胞是否存在的生物学界限，不能原样移到其他 MPP。

### 2.5 一项需要先排除的训练混杂

`src/nucseg/cellvit/engine.py:38-49,206,231`（行号为 2026-10-08 复核时；写作时为 151-190）：初始lr=3e−4、每epoch×.85、编码器前25epoch冻结。解冻时学习率约为：

`3e-4 * 0.85**25 = 5.1593e-6`。

这是既有配方，不是本轮确认的bug。下一轮应先用尺度×训练日程的2×2对照，判断尺度效应是否依赖早期快速衰减、较弱的后期编码器适配；不直接改掉原基线然后与历史结果混比。

### 2.6 新发现：HV目标的固定30px门槛改变了x1/x2的小实例监督（已运行探针）

在本次实现改动前，沿目标构造追踪得到（以下行号为发现时版本）：`cellvit/data.py:144-151` 先增强、再上采样标签、最后调用 `hv_targets`；`hovernet/data.py:46-49` 未传入尺度；官方 `third_party/hover_net/models/hovernet/targets.py:33` 固定 `remove_small_objects(..., min_size=30)`，只给保留下来的实例计算HV。NP前景仍由`inst>0`生成，不因这个门槛消失。

本轮在CPU直接调用现有 `hv_targets`，对同一个64×64标签中的完整矩形核作精确2倍nearest标签放大，得到：

| 原始实例面积 | x1非零HV像素数 | x2非零HV像素数 | NP监督 |
|---|---:|---:|---|
| 16px（4×4） | 0 | 63 | 两种尺度均保留全部核像素为前景 |
| 25px（5×5） | 0 | 99 | 同上 |
| 30px（5×6） | 29 | 119 | 同上 |
| 36px（6×6） | 35 | 143 | 同上 |

非零数比目标面积少1是这个矩形的中心HV恰好为零；关键是16/25px对象从**整对象HV全零**变成具有方向距离场。固定30个工作像素意味着x2只需约7.5个原生面积像素就能进入HV构造，而x1需要30。

可复现的CPU探针（在项目固定Python环境中执行，不改文件）：

```bash
CUDA_VISIBLE_DEVICES='' python -B - <<'PY'
import numpy as np
from nucseg.hovernet.data import hv_targets
for h, w in [(4, 4), (5, 5), (5, 6), (6, 6)]:
    native = np.zeros((64, 64), dtype=np.int32)
    native[20:20+h, 20:20+w] = 1
    for scale in (1, 2):
        inst = np.repeat(np.repeat(native, scale, axis=0), scale, axis=1)
        hv = hv_targets(inst)
        print(h*w, scale, int((inst > 0).sum()), int(np.any(hv != 0, axis=-1).sum()))
PY
```

**结论范围：**目标支持集合随尺度变化已由代码与探针证实；它对真实Dead/边缘实例、训练梯度和最终PQ的贡献尚未测量。它来自沿用的官方构造，不直接等于应当修改的bug，也不是说小对象完全没有监督——NP/TP仍在，HV则被监督为零。

这使“只有工作分辨率变化”的严格单因素解释不充分。优先实验应为**工作尺度×原生面积支持门槛**：保留原(x1,工作30)、(x2,工作30)，加入(x1,工作8)、(x2,工作120)作为近等原生支持范围对照；先固定日程、保持其他实现一致。精确2倍nearest时实例面积为原始4倍，工作30对应原生整数面积至少8。必须报告增强后实际面积支持和非零HV比例，而不只报告配置值。

同时，当前HV中心是在增强/裁剪之后的**可见mask**上计算（官方targets.py:58）；当前模型并没有明确把“完整中心在视野外”作为NP背景。路线A应研究跨裁剪目标变化和身份一致性，不能先假定一个代码中不存在的负样本规则。

## 4. 建议的三条候选路线与优先级

### 路线A：裁剪一致、观测过程感知的可见实例学习（主研究假设）

**问题：**网络被要求将“完整小核”“较大核的可见残片”“一个碎裂对象中的多个碎片”输出成相同形式，但训练监督未显式表述可见性和对象单位，是否制造了可定位的失败？

**可证伪设计：**

1. 仅在训练折内部，从原图中本来完整的GT核构造嵌套FOV；保留对象身份，得到裁剪前后已知对应关系。
2. 分别监督可见mask、截断状态和跨视野对象一致性；完整中心若作为辅助潜变量可在小视野外，但最终输出仍需对齐PanNuke可见实例定义。**当前NP并不要求完整中心位于图内，HV按可见mask重算**，因此先验证跨裁剪目标变化是否构成真实训练难点，不能人为制造“外部中心=背景”的假问题。原图本身已经触边的对象不能臆造完整中心或完整轮廓。
3. 区分FOV删去证据与单纯平移引起token栅格相位变化；另控制插值、训练尺度与解码像素常数。
4. 不要求推理时获得相邻未知图块，不生成假“真值”视野外细胞。验证时保持原图原GT。

**相对LSP-DETR的待验证差异：**它已建模径向边界区间；我们要检验的是跨裁剪对象身份、可见mask一致性与视野外完整中心的监督关系。仅放宽边界损失不够。

**最低对照：**原基线、crop augmentation-only、border-ignore、LSP式截断损失、同参数普通CNN adapter；必要时与LSP-DETR可复现配方比较。预声明自然截断实例为机制主要端点，内部Dead、整体strict/bPQ和成本为伤害护栏；不强求一种针对边缘的方法也提高内部Dead，但不能声称它解决全部Dead。外部数据检验相同机制的迁移。

**止损：**若效应只出现在人工裁剪，真实边缘/外部数据无收益；或强基线crop augmentation已解释全部收益，则不进入新架构大规模训练。

### 路线B：新增实例的集合级效用，而非更复杂的类别阈值（最低成本推进路径）

固定x1基础集合与x2候选，分离学习：

- 候选能否与当前标注匹配；
- 匹配后的mask质量；
- 匹配条件下的类别；
- 加入基础集合后的重复、分裂和总体误报代价。

训练候选必须由**训练折内部交叉拟合**产生；一个样本的候选生成器不能训练过它的标签。最终验证折只作冻结候选族的校准/选择，不能先训练新头、再把同一验证折当独立选择集。既有val候选可用于描述和冻结基线重放，不偷换为训练后仍“独立”的val。

还需检查OOF生成器（较少训练数据）与最终全训练折生成器的候选数量、置信度和误报分布是否变化。涉及统计认证时，先冻结proposer、utility learner和候选策略全链，用独立于其学习/选型的校准单位检验；不得在一个校准集上无限调模型后再套单模型风险界。

**一个有用但有限的推导。** 对固定图像、固定基础集合、互不重叠且不改变旧配对的单个新增候选，忽略评测epsilon，写二元PQ为 `q=S/D`，`D=TP+0.5FP+0.5FN`：

- 新增FP：分母+0.5、分子不变；
- 新增与原漏检GT匹配的TP：分母也+0.5、分子增加IoU。

因此其期望改善条件为：

`P(match) * E[IoU | match] > q/2`。

不是类别置信度>.9，也不是普遍的存在概率>.5。**q和GT不能在推理时使用**；需仅用训练数据学习代理效用。这不是新的通用定理或已验证算法，只是本候选机制的设计依据。

真实多候选、类别错误、strict缺类惩罚、组织宏平均和评测epsilon均需用实际evaluator定义效用与对照，固定去重、加入顺序及重匹配规则，不能直接把此式扩展成保证。严格不重叠预测在IoU>.5下不能同时匹配同一GT；一旦允许overlap、合并/替换或较低匹配阈值，必须另行分析竞争。增加“独立评分+固定去重”对照，检验集合模型是否确有必要。对高置信但不匹配候选，不能未经专家审计便按“漏标”忽略。

**最低对照：**冻结EF-P2、面积+类别+边界的逻辑回归、再加简单形态特征、前景objectness、Mask-IoU quality scoring、同算力TTA/同尺度集成。复杂模型如果不超过低维回归，应停止复杂化，保留简单结果。

**风险表述：**先叫“效用学习/风险审计”，不叫“保证无损”。LTT可对固定候选和独立校准数据作有限样本测试 [T2]，但样本独立性、loss定义、集合匹配、组织加权和分布迁移必须逐项处理。CRC不能直接套在非单调PQ菜单上 [T3]。

量级警示：若把配对损失仅界为[-1,1]，用最朴素Hoeffding+10候选Bonferroni，95%置信下把最坏情况界宽压到.001需要约**1,060万独立样本单位**。这只是保守上界的示例，不是实际功效分析或所需患者数估计；它说明不能拿几千高度相关patch加一个conformal标签便声称证明极小非劣性。方差自适应界可能更紧，也可能最终只能认证identity。

### 路线C：有独立身份验证的跨模态/生成监督（高风险、高资源备选）

只有当人工审计支持标签过程/死亡形态是重要瓶颈，且可获得新患者配对材料时，才开启此线：

- 新患者H&E与mIF/IHC/空间测量形成teacher信号；将核/细胞边界、凋亡、坏死分开标注。
- 分子标志用于支持某类状态，不把单一阴性当成“活”、不把凋亡信号当全部Dead真值；配准误差、mask来源和专家不确定区单列。
- 条件生成优先解决可核查的失败类型，独立判定生成对象身份，禁止同一个teacher既制造类别标签又证明其正确。
- 与真实重采样、上下文匹配copy-paste、普通类型条件生成作等样本/等算力对照；不能以FID或视觉好看来证明下游标签可靠。

VitaminP、HistoSmith、NucleiMix已覆盖很多基本想法，真正潜在贡献是**独立的对象/身份验证如何改善受观测过程影响的实例学习**。若配对样本和专家不可得，不建议用H100把旧binary ControlNet扩量。

### 推荐顺序

**先B的简单模型与审计，平行做A的受控干预；只有两个机制实验之一通过止损门槛，再做A/B整合和单模型压缩。C保留为有新数据条件时的升级路线。**

普通双尺度蒸馏已有直接先例 [S5]。若后续压缩，需只蒸馏训练内可验证的增量证据、保留x1已正确几何，且对x2-only漏检目标不能强制要求与x1一致；否则会把希望恢复的对象一并压掉。新意仍需靠机制与独立验证，而非“teacher/student”命名。

## 6. 数据与统计设计：比增加种子更重要

1. **现有PanNuke三fold都已经参与研究开发。**重新划分同一批图、再加种子或重新预注册，并不能恢复完全未触碰的确认性测试。继续报告官方三split，但明确是复用benchmark。
2. 新模型学习/选择使用训练内cross-fit与保留calibration；最后的独立test必须保持不见结果。若只具patch标识，无patient/slide关联，则只能作条件于已知分组的分析，不冒称病例级保证。
3. CoNIC、MoNuSAC、PUMA已使用，只能作固定回归/外部复验。NuInsSeg与CryoNuSeg可申请为新检测/边界评估候选，但需核查本项目历史使用、WSI/患者关联、数据许可和所有teacher预训练来源。
4. NuInsSeg/CryoNuSeg没有本轮已核实的Dead分型标签，**不能用它们证明Dead外部泛化**。NuInsSeg还需固定推荐标签版本及不确定区域处理，不能在两套mask之间按结果选择。
5. 真正外部Dead验证优先新患者/新中心H&E，专家分别标注apoptotic、necrotic、unknown，再预先映射到Dead。独立样本量按患者/slide及Dead阳性覆盖规划；不要把新增细胞计数当新增独立样本。
6. 原始官方GT成绩与独立专家/分子辅助审计分表，不覆盖原GT或事后选有利评审者。模型辅助标注可能有偏差，但本轮未证明PanNuke存在特定系统漏标。
7. 预先指定一个主要效能端点和少量护栏。候选建议：Dead PQ最小有用点估计+.005、其差值区间下界>0；同时strict Dead不恶化、bPQ与strict mPQ的区间下界高于预声明容忍量。**+.005和容忍量仅是待论证的设计建议**，最终应在独立test前依用途与独立开发功效分析冻结，不能用当轮差值SD反向放宽。
8. 不确定性优先患者/slide分层重采样；种子变动与图像/病例变动分开呈现。若fold3的两个split同时进入bootstrap，要共享相同病例重采样索引，避免假独立；最终仍按官方split平均，并另给不重复fold的诊断。
9. 公开训练数据、segmentation监督、FM预训练、teacher蒸馏来源四层provenance。基础模型曾见同来源未标注WSI与直接使用全部PanNuke分割标签不是同一风险，不混为一谈，但都应披露未知处。

## 7. 算力申请：分阶段，而不是先买集群再找问题

以下是**规划额度，不是已批准资源，也不是测得的H100性能**。本轮可读取的既有130epoch日志中，x1记录的训练循环耗时约1.47–3.84h，x2约5.10–15.25h；日志样本不完整且运行条件不受控，部分有重启重复epoch，不能当精确硬件基准。日志`time`还不包括全部验证、存储与端到端成本。H100额度必须先用代表性运行实测吞吐和显存更新，不承诺固定A100→H100加速倍数。

| 阶段 | 建议资源 | 额度与用途 | 启动门槛 |
|---|---|---|---|
| 机制与审计 | CPU；可预约单张40–80GB训练GPU；专家工时 | **约60–150 A100级GPU·h**初始上限，覆盖小型日程对照、cross-fit候选、轻量head和成本测试；不是训练大FM | 先固定问题、数据分组与小菜单；E1并行申请专家 |
| 候选方法确认 | **4×H100 80GB**，优先独立运行并行，不必每个小模型都4卡DDP | 一周预约上限672 GPU·h，**目标实际200–500 GPU·h**；用于通过初筛的1–2方法、必要强对照、匹配种子与外部验证 | A或B超过简单强对照；独立验证数据可用；完成H100 pilot后再定任务数 |
| 跨模态/多源扩展（可选） | **8×H100 80GB**，充足CPU RAM、本地NVMe与合规数据存储 | 两周上限2688 GPU·h；只有多源/配对资料与明确teacher方案后，才按实测制定实际预算 | 有新增生物监督和数据协议；小规模证明身份/标签忠实性提升；否则不申请 |

存储规划：轻量阶段预留约0.2–0.5TB，确认阶段约1TB，配对多源扩展2–5TB起步并按实际图像面积核算；只缓存必要OOF logits/候选与最终模型，避免每epoch全量权重。容量均为可修改的预算估计，写入前检查目标磁盘；不解包PanNuke float64原始zip。

**比H100更优先的资源申请：**两名能独立评审的病理专家、首次审计工时、新患者/WSI可追溯访问、明确许可、独立保管的holdout。若这些资源缺失，应把结论定位为PanNuke机制研究，而不是用更多GPU掩盖验证缺口。

## 8. 对旧路线与写作的调整

保留历史记录，不重写实验结果；但以下旧句不能继续作为当前总论：

- “Dead检测缺陷不可由数据侧干预修复” → **仅所测CP1/SYN1未成功**，尤其binary ControlNet没有检验类别可控生成。
- “固定标签的CF构造上不能施加检测压力” → **当前renderer未复现架构间真实检测域差**；固定标签并不排除删弱对比、遮挡或边界扰动带来的检测压力。
- “检测优先架构不能解决问题” → **所评KongNet发布配方未解决**；不能否定整个家族。
- “Dead=apoptotic” → **PanNuke合并apoptotic与necrotic**。
- “SOTA天花板约.51” → **旧时点、旧检索范围的概括**；2026新自报结果需逐项协议核验，不再使用固定天花板。
- “H100能恢复x2细节” → **插值没有新光学证据**；算力只帮助学习、规模与实验覆盖。

可以形成的论文叙事：

> 核实例检测的失败不仅取决于像素分辨率，还取决于对象被如何观察、裁剪和标注。我们通过受控FOV干预与独立对象审计识别可修复机制，再学习对基础实例集合有可验证收益的增量预测，并在严格的准确率—成本与独立数据框架下评估。

这是研究问题与预期贡献结构，**不是结果摘要**。若A/B均不能超越简单基线，仍可产出可信的机制与标注不确定性研究，但应据实降低方法创新主张。
